# Training History Archive

This directory stores historical summary documents that no longer need to sit
at the repository root.

- `TRAINING_LOG_ARCHIVE_FULL_2026-04-17.md`: immutable full snapshot predating
  the slim canonical log.
- `TRAINING_LOG_ARCHIVE_FULL_2026-07-30.md`: immutable verbatim snapshot of the
  canonical log through the completed Baby teacher baseline and recovery
  milestone. It is `118685` bytes with SHA256
  `2699931c8621309d6f09127629645990216b3ed19bae18dc7cf3f56a0b6dd5c8`.
- `TRAINING_HANDOFF_2026-04-10.md`: short historical handoff.
- `TRAINING_HANDOFF_2026-04-11.md`: detailed historical handoff.

Use `../../TRAINING_LOG.md` first for current state. Raw per-run output remains
under `../../logs/`, which is also the default output directory used by the
active logger.
