# Archive Index

This directory contains preserved historical material that is not part of the
active training entry point.

- `training/`: historical training handoffs and the full pre-slim training log.
- `run_patent_results/`: complete legacy Photo result directories generated by
  the standalone `codes/run_patent.py` line.

Nothing in this archive has been deleted. The active experiment path remains
`codes/main_mmlight.py`, and the canonical current experiment memory remains
`TRAINING_LOG.md` at the repository root.
