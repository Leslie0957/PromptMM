## 1. 路线结论

若创新点1闭环后的诊断支持本路线，则在第一创新点的无投影方向蒸馏学生上，
增加“教师语义可靠性 + 推荐梯度兼容性”联合门控。目标不是继续搜索一个
更好的固定或动态 `alpha`，而是回答：

> 对当前实体和模态，这条教师语义是否稳定可信，并且是否与推荐任务方向
> 一致？

该路线对应原候选中的“语义迁移机制优化”，并将“鲁棒性增强”作为验证维度。
缺失或噪声模态只作为压力测试，不作为方法主标题。本节是条件性候选定义，
不是创新点2已经最终确定的声明。

## 2. 研究问题与假设

- RQ1：冻结教师产生的语义目标是否存在显著的实体级、模态级稳定性差异？
- RQ2：不同语义分量是否会与 BPR 推荐目标产生可测量、且能预测性能退化的
  梯度冲突？
- RQ3：联合可靠性和梯度兼容性选择知识，能否超过固定
  `item-image/item-text/user-image/user-text = 1/0.3/0/0` 的主线配置，
  同时保持纯 ID 推理？
- H1：低稳定性教师目标更容易出现高语义损失、负梯度冲突和性能退化。
- H2：联合门控优于仅可靠性、仅梯度兼容性以及固定权重。
- H3：收益在教师模态受噪时更明显，且不增加学生推理成本。

## 3. 仓库内动机证据

以下结果来自旧 Amazon 探索日志，指标顺序均为 Recall@20 / NDCG@20 /
Precision@20。它们存在旧数据身份、重复模态和 Test 选择等历史问题，只能
作为选题动机。当前 Baby 协议已经修复，并已完成合规的基线/主方法三种子
恢复结果；但这些主结果仍不能替代创新点1尚缺的组件和结构消融。

| 现象 | 已有结果 | 含义 |
| --- | --- | --- |
| 蒸馏确实必要 | 固定主线 `0.10948 / 0.11405 / 0.01935`；关闭蒸馏降至 `0.08209 / 0.09161 / 0.01519` | 不能简单删除语义监督 |
| 过强监督会崩溃 | `alpha=0.4` 较 `0.3` 下降约 `25.35% / 22.84% / 25.89%` | 存在明显负迁移区间 |
| 无差别启用四头有害 | 四头全 1 为 `0.07659 / 0.08220 / 0.01315` | 不同实体和模态不应等价处理 |
| 用户语义可能冲突 | 增加 `user-image=0.1` 后低于无用户分支 | 需要选择性拒绝教师指导 |
| 文本作用依赖结构 | 投影分支加入弱文本后下降，无投影 `image=1,text=0.3` 为当前最佳 | 不能把某一模态永久判为有害 |
| 存在种子敏感性 | 三种子均值 `0.10402 / 0.11021 / 0.01836`，最差种子 Precision 仅高旧基线 1.08% | 仍有稳定性优化空间 |

## 4. 方法定义

记学生 ID 嵌入为 `s_e`，冻结教师的实体 `e`、模态 `m` 语义为
`t_(e,m)^0`。其中 `e` 属于用户或物品，`m` 属于图像或文本。

### 4.1 基础方向损失

```text
L_dir(e,m) = || norm(s_e) - norm(t_(e,m)^0) ||_2^2
```

该项继承第一创新点，不作为第二创新点的新贡献。

### 4.2 实体-模态教师可靠性

对同一模态施加 `K` 次轻量独立扰动，冻结教师得到
`t_(e,m)^1 ... t_(e,m)^K`：

```text
r(e,m) = clip(mean_k cosine(t_(e,m)^0, t_(e,m)^k), 0, 1)
```

- 扰动候选：小幅高斯噪声、特征 masking、feature shuffle 的轻量版本。
- `r(e,m)` 在学生训练前离线计算并缓存。
- 应在各模态内部做分位数或温度校准，避免图像和文本可靠度量纲不同。
- 可靠性只刻画教师目标的稳定程度，不直接等同于推荐价值。

### 4.3 推荐梯度兼容性

```text
g_rec(e)   = grad_(s_e) L_BPR
g_sem(e,m) = grad_(s_e) L_dir(e,m)
kappa(e,m) = cosine(g_rec(e), g_sem(e,m))
c(e,m)     = ReLU(EMA(kappa(e,m)))
```

- 优先在学生嵌入空间计算，避免逐样本全参数梯度。
- 第一版可采用“实体可靠性 + 批次分量梯度兼容性”，降低额外反向开销。
- 门控值执行 stop-gradient，不引入二阶梯度。
- 当 `kappa < 0` 时，该语义分量会把学生推向与推荐目标相反的方向，应被
  抑制或拒绝。

### 4.4 联合可靠语义选择

```text
a(e,m) = stopgrad(r(e,m) * c(e,m))

L_RGCS = (1 / |Omega_B|) * sum_(e,m in Omega_B) a(e,m) * L_dir(e,m)
L      = L_BPR + alpha * L_RGCS
```

关键约束：

- 初期实验固定 `alpha=0.3`，只验证细粒度知识选择，避免与普通动态
  `alpha` 混淆。
- 使用固定候选数 `|Omega_B|` 归一化，不除以 `sum a(e,m)`。否则整体
  可靠性很低时，门控本应产生的蒸馏衰减会被抵消。
- 教师、可靠性缓存和门控仅用于训练；推理仍只保留用户和物品 ID 嵌入。

## 5. 与第一创新点的边界

| 第一创新点 | 第二创新点 |
| --- | --- |
| 解决重型多模态教师的部署成本 | 解决教师指导的异质可靠性与负迁移 |
| 训推解耦、非对称无投影方向蒸馏 | 实体-模态可靠性估计与梯度兼容选择 |
| 使用固定主线权重 `1/0.3/0/0` | 按当前实体、模态和优化状态选择知识 |
| 贡献重点是结构和推理部署 | 贡献重点是训练期可靠知识迁移 |

第二点继承第一点的无投影方向损失和轻量推理，但不重复主张这些结构。
固定 `1/0.3/0/0` 是第二点的直接基线，不是第二点贡献。

## 6. 文献边界

- [PromptMM, WWW 2024](https://arxiv.org/abs/2402.17188)：已有任务自适应
  Prompt 和模态重加权，不能把“自适应模态权重”单独作为新意。
- [Modality-Balanced Learning, ACM MM 2024](https://arxiv.org/abs/2408.06360)：
  已按反事实模态贡献自适应调整蒸馏损失。本路线必须突出实体级稳定性和
  梯度兼容性的联合约束。
- [Less or More From Teacher, ICLR 2024](https://proceedings.iclr.cc/paper_files/paper/2024/hash/6aa4967920e495e90aeeaa3acf18d019-Abstract-Conference.html)：
  已学习样本级教师融合比例。
- [DTO-KD, ICLR 2026](https://iclr.cc/virtual/2026/poster/10009597)：已有
  任务损失与总 KD 损失的梯度动态平衡，是梯度模块最重要的直接对照。
- [KRD, ICML 2023](https://proceedings.mlr.press/v202/wu23m.html)：已有通过
  扰动稳定性评估 GNN 节点知识可靠性的思路。不能单独声称“扰动可靠性”
  是全新方法。
- [FeatProp](https://arxiv.org/abs/2403.19841)、
  [MILK](https://arxiv.org/abs/2405.15783)、
  [DGMRec](https://arxiv.org/abs/2504.16352)：分别处理缺失特征传播、
  缺失环境不变学习或缺失模态生成。RGCS 不重建模态，缺失和噪声只作为
  教师目标压力测试。

暂定差异化表述：

> 联合建模多模态推荐中实体-模态教师目标的扰动稳定性与其相对 BPR 目标的
> 梯度兼容性，从而抑制有害语义向纯 ID 学生的负迁移。

完成系统文献检索和直接基线复现前，不得写“首次提出”或作强新颖性声明。

## 7. Go / No-Go 诊断

第一项工作必须是诊断日志，而不是直接实现完整门控。

1. 修正现有实验协议：验证集选择 epoch，测试集只作最终评估；固定并显式
   记录教师 checkpoint。
2. 保持训练目标不变，在早、中、晚期采样 batch，记录四个语义分量的
   `kappa` 分布、负余弦比例和梯度范数。
3. 生成轻扰动教师语义，统计各模态 `r` 的分布、实体排序稳定性，以及高低
   可靠组的语义损失差异。
4. GO：多个 epoch 和种子中持续存在负梯度冲突；冲突排序与用户侧、文本侧
   已有消融基本一致；同时可靠性存在稳定异质性。
5. 降级：只有可靠性成立则测试 reliability-only；只有冲突成立则测试
   compatibility-only。
6. NO-GO：梯度冲突几乎不存在，可靠性近似常数，两者不能解释已有消融，
   或门控退化为固定全开或全关。
7. 完整方法若不能稳定超过校正后的固定主线，或只在单一种子、单一噪声点
   改善，不作为第二创新点。

## 8. 最小实验闭环

### 8.1 单种子筛选

在校正后的统一协议下固定 `alpha=0.3`、无投影、无 warm start、
`student_lr=6e-5`：

1. Fixed：固定 `1/0.3/0/0` 主线。
2. Reliability-only：仅教师可靠性。
3. Compatibility-only：仅梯度兼容性。
4. RGCS：可靠性与梯度兼容性联合。
5. 可选诊断：RGCS 下重新开放弱用户侧，检查门控能否自动拒绝有害监督。

### 8.2 正式结果

- Fixed 与 RGCS 均运行 seeds `2022/2023/2024`。
- 报告均值、标准差、最差种子和相对固定主线的变化。
- 核心消融：去 `r`、去 `c`、联合；四头全开作为负迁移参照。
- 压力测试：教师目标提取阶段分别施加图像和文本 masking 或噪声，建议先用
  强度 `{0, 0.1, 0.3}`。
- 指标：Recall/NDCG/Precision@20、负梯度比例、有效门控比例、各模态平均
  权重、训练时间。
- 推理理论上无新增开销，最终只需复跑一次独立学生效率基准确认。
- Amazon 完成 GO 后，正式论文主张前至少补一个第二数据集。

## 10. 备选方向

1. Reliability-only：可靠性异质明显但梯度冲突弱时采用，创新性低于联合方案。
2. Compatibility-only：冲突明显但教师稳定性近似一致时采用，必须与 DTO-KD
   做严格区别。
3. 面向缺失与噪声模态的教师语义重建一致性蒸馏：只在 RGCS 诊断失败、且
   当前方法在模态退化下明显崩溃时重新评估。该方向已有较强直接工作，实验
   成本更高。
4. 语义与排序行为联合蒸馏：RGCS 两项诊断均失败后再考虑；原 PromptMM
   已包含排序蒸馏，需非常谨慎地区分。
5. 课程学习或动态 `alpha`：只可作为工程基线或消融，不能单独承担第二
   创新点。
