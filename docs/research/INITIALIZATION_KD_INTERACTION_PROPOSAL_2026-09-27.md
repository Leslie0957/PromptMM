# 初始化转移 × 持续方向监督：立项结论与实施交接

日期：2026-09-27。状态：评审与计划完成；未修改训练实现、未声明或运行新实验。

## 1. 立项结论

**值得准备一个受控四臂实验，但当前定位是第一项工作的机制补充，不认定为第二个独立算法。** 若用户唯一目标是尽快获得第二项新算法，不建议把这四臂训练当作必经投资；它能解决归因缺口，不能保证生成新机制。

问题：固定同一教师资产、纯ID学生和训练协议时，教师最终表征初始化是否改变持续物品图文方向监督的增量排序收益？初始化转移与持续约束是互补、部分替代，还是既有差异由其他训练条件造成？

第一项工作检验固定方向配方和文本结构的有效性；本问题检验两种知识转移路径的交互。问题可区分，但研究对象相连；不能仅拆成两章即声称两个创新点。阶段性停KD、适应性调度均不是当前方法，也不是待执行队列。

## 2. 现有证据与反证边界

- [主表](../paper/INNOVATION1_FIXED_MAIN_TABLE_2026-09-26.md)：Full在两数据集所测配置优于BPR，不证明全面优于发布版或文本单因素因果。
- [机制综合](SPORTS_INTEGRATED_MECHANISM_CONCLUSION_2026-09-26.md)：随机初值Full/image及real/sham配对支持该预算下的结构信息作用，未证明必须全程蒸馏。
- [共享暖初始化审计](SPORTS_SHAREDINIT_PAIR_AUDIT_2026-09-23.md)：seed2022、300轮，Full/BPR最佳Val R20约0.095438/0.095478；起点0.094184。未证明额外KD收益，更未证明统计等价。不能把高暖启动分数归给持续KD。
- [P1a审计](CROSS_INTERACTION_P1_AUDIT.md)：372对单步筛查四组G1/G2停止。冷epoch293、暖epoch282均为训练后状态，且统一暖缓存；没有早期知识进入、联合训练或长期作用证据。它要求停止原筛查配置，不是新假设的正面支持。

尚缺证据：初始化改变KD增益的可重复交互、初始信息与尺度分别的贡献、知识主要在早期进入、后期KD有害/冗余、可靠的停止判据、训练成本可显著下降，以及任何第二算法创新或学位充分性。

## 4. 最小可识别实验：先只做路径交互

提议在Sports固定300轮预算下，按seed2022组成以下四臂。**这是未来设计，不是已授权运行或可直接套用旧profile的命令。** 300轮沿用现有冷/暖机制预算，避免事后调整长度；不以最佳epoch靠近末尾为理由自动延长。

| ID | 起点 | 优化目标 | 作用 |
|---|---|---|---|
| R0 | 同一seed的随机用户/物品ID表 | BPR | 随机基础线 |
| R1 | 与R0逐位相同 | BPR + 原Full | 随机起点持续KD |
| T0 | 固定教师最终用户/物品表 | BPR | 表征初始化后微调 |
| T1 | 与T0逐位相同 | BPR + 原Full | 两种转移路径结合 |

四臂统一ID64、点积BPR、无学生图传播/投影、固定教师及prompt、正物品KD、用户KD为零、图像0.3/1.3和文本0.09/1.3。建议沿用lr6e-5、batch1024、AdamW decay0.01；实施者必须静态展开全部profile、CLI和正则项并核对后冻结，不能只看parser默认值。任何未列共同参数继承哪个锚须明确，不在运行中猜测。

每臂重新建立AdamW，空moments、step0、相同超参数；不继承旧epoch282/293的学生或优化器。四臂共用一个seed的完整三元组tape、批次顺序、评估频率和数值实现。固定缓存同时提供T0/T1最终表及R1/T1模态目标；R0/T0不开KD，但数据身份也记录共同目标锚。

主终点为**固定第300轮Validation Recall@20**，每seed计算 delta_R=R1-R0、delta_T=T1-T0，交互 I=delta_R-delta_T。预期方向I>0来自旧边界，但须允许反证。最佳Validation Recall（同频率、同样的最早最大值选择）及同轮NDCG、固定轮次曲线为次终点，不与固定末轮混用。记录epoch0但不混入主终点或最佳训练checkpoint选择；初始高分不能当持续训练增益。

新四臂使用Validation作研究/选模，不做Test。实施准备期间连Validation也不读取；未来运行须单独授权。不得为了“不读Test”仅关闭ranking，数据加载器也必须禁止打开Test文件。

一个seed只做可行性与描述性交互，不作显著性/普遍性声明。若按事前准则值得复制，再分别授权seed2023/2024；教师表固定，种子主要改变随机起点和训练tape，不能把相同暖起点说成独立教师重复。没有自动12臂队列，暂不扩Baby。三seed仍可能不足以判定等价。

## 5. 归因限制和真正的停止条件

教师最终用户/物品表包含协同结构与多模态融合信息；KD仅监督物品模态分支。四臂识别的是**完整初始化方案与指定KD配方的交互**，不是同一知识两次输入的冗余性。随机与教师起点也同时改变范数、初始margin、方向与初始质量；这些是初始化处理的一部分，不能唯一归因语义。

首次四臂不额外堆置换/范数归一化臂，以控制成本。记录两表范数分布、初始排序/损失及后续变化作为描述性协变量；若后续主张“结构知识”因果，需另设匹配尺度等对照。不能通过事后归一化直接改写本四臂处理。

| 新结果 | 决策 |
|---|---|
| I有重复且实际有意义的正差；delta_T也正 | 支持KD增益受初始化方案影响，但仍有互补，不能说暖起点使KD无用 |
| I有重复正差；delta_T落在事前小效应区间内 | 支持该设置的有限增量边界；非劣/等价需独立误差界和足够精度 |
| 两个delta相近且精度足够 | 不支持强初始化交互，结束该机制假说扩展 |
| I方向不稳或区间很宽 | 证据不足；不称无效/等价，不无限加seed |
| 只在最佳值而非末轮/轨迹出现差异 | 限定为选模表现，不能声称持续知识保留机制 |
| 差异存在但简单初始化配方足以解释 | 完成第一项工作机制补充，不自动设计第二算法 |

在新结果前冻结实际意义门槛delta_I（绝对Recall单位）、若主张不损失时的非劣界epsilon及资源上限。它们必须有任务意义/成本依据；本次不从P1a的1e-10、旧Test差值或任意百分比推导。实施者可提交依据明确的候选判据；若无法合理确定，保持声明不可启动，不能看完新曲线才选门槛。单seed不能做有效精度判定时，仅记录探索结果；升级多seed要单独决定。

实际训练/评价成本未知。历史暖配对约8h17m但非受控计时，P1a数分钟也不能外推四个300轮。先静态估算工作量、磁盘、评估开销及manifest输出；必要的真实资源smoke须另行声明、独立目录和限时。若只为第二算法而成本过高，可停止在立项阶段，并保留为论文讨论问题。
