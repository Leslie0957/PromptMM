## 1. 决策与证据基点

选择“修改后推进”：先验证跨交互监督分配是否存在可利用空间，再决定是否值得开发方法。工作问题为：**在冻结教师、纯 ID 学生和实际 AdamW 更新下，训练内部的跨交互信息能否帮助分配物品图文监督，并优于简单聚合梯度及统一减弱蒸馏？**

保持 ID64、无学生图传播、无投影头、固定教师及 prompt、正物品模态分支方向损失、用户侧权重为零。Full 的图像/文本实际系数仍为 0.3/1.3、0.09/1.3。本次不改变任何参数。不重新包装线上降本，不先实现 RGCS、IRV 或神经门控，不为对应专利开启用户支路。

已有证据以 [当前日志](../../TRAINING_LOG.md)、[固定主表](../paper/INNOVATION1_FIXED_MAIN_TABLE_2026-09-26.md)、[机制综合](SPORTS_INTEGRATED_MECHANISM_CONCLUSION_2026-09-26.md)、[立项复核](../paper/INNOVATION1_RATIONALE_REVIEW_2026-09-26.md)为准。Full 相对 BPR 有固定配置收益；真实残差结构有条件地有用；暖启动单 seed 未显示额外 KD 收益；这些都不证明跨交互选择有效。暖启动持平是有效负结果，不是失败运行。

## 3. 新颖性门槛：不能只战胜局部门控

固定状态下，单物品模态梯度记为 g(i,m)。对探测分布 Q，SGD 一阶平均效用为 eta * E_Q[grad loss]^T g(i,m)。因此平均跨交互一阶效用就是聚合梯度内积。更准确估计均值可能有应用价值，但不会自动成为新的学习原理。

进一步，在同一批次/同一状态、detach 的交互权重 a(u,i,m) 下，由于 D(i,m) 不依赖用户，sum_u a(u,i,m) D(i,m) = (sum_u a(u,i,m)) D(i,m)。逐交互标量门控在此条件下可归并为物品权重；不为追求“不可归约”而改变学生结构或让 gate 反向传播。跨交互是信息来源，物品—模态是动作单位，两者不矛盾。

原始文献核查：

- [Du 等梯度相似性辅助学习](https://arxiv.org/abs/1812.02224)：已有梯度余弦自适应权重。
- [Ren 等样本重加权](https://proceedings.mlr.press/v80/ren18a.html)：已有基于评价集反馈的元梯度权重；虚拟更新后评价不是新范式。
- [PromptMM §3.2.2/4.3](https://arxiv.org/html/2402.17188v1)：已有模态感知解耦和软标签重加权，不能写成所有既有方法只用固定监督。论文机制与本地共享教师适配仍须分开。
- [GUIDE，IJCAI 2026](https://www.ijcai.org/proceedings/2026/361)：官方摘要确认用户—物品上下文及元学习门控；本次不宣称其逐式实现与本方案等同。
- 前次已核对 [MetaDistil](https://aclanthology.org/2022.acl-long.485/) 与 [TAG 作者说明](https://www.research.google/blog/deciding-which-tasks-should-train-together-in-multi-task-neural-networks/)。Student Customized KD、C2KD 是后续逐式核查优先项。AI 文件中的 HAPLRec、DTO-KD、CB-DistillGrad、RW-KD 等名称不因出现于意见中而视为已完成原文核查。

只有明确识别并解决简单聚合门控遗漏的问题（例如正负角色估计偏差、有限探测下的不确定性、实际优化器下的一阶误判），且在同数据/探测预算的消融中证明其作用，才继续主张独立方法差异。不同于梯度公式也不是创新性的充分条件，最终机制确定后仍需定向原文审查。

## 4. 固定效用定义与数据边界

状态 S 包含模型、AdamW 一/二阶矩及 step、学习率/调度、随机状态。两分支由同一个 S 和 BPR 批次出发：A 执行 base；B 执行 base+a(i,m)D(i,m)。不是先 BPR 再额外做一个 KD optimizer step。U1 = ProbeLoss(A)-ProbeLoss(B)，正值仅表示指定探测分布下 BPR surrogate 改善。

- 第一轮 base=BPR，使用真实 Full 系数、原 batch reduction 及该物品全部正例出现次数，不因删除其他项而重归一化系数。每次干预记录 multiplicity，按实际梯度而非标签去重猜测强度。
- 选择前置检查再用 base=Full 去掉该项，对比 Full，测当前组合中的删除边际；其他模态、物品保持一致。单项 U1 不能直接相加预测联合选择。
- U5 定义为第一次干预更新后再做四步共同 BPR，共五步。继续各分支各自的优化器状态，回放相同数据/RNG，不能把两分支动量重新合并。报告这四步中焦点物品/受影响用户的实际再出现次数；没有再次受影响的 U5 保持，不算持续学习机制证据。不为了得到持续性而事后强制加入焦点物品。
- 主标签为训练内部探测 BPR loss，分开正物品角色和协议负候选角色，按真实采样器概率合成；过采样时记录重要性权重、方差和有效样本量。条件于涉及 i 的效用与总体贡献分别报告，不用 50:50 任意混合冒充训练分布。未观测负候选不是已知负偏好。
- 原始梯度 dot/cos 是预测器；实际 AdamW 两分支差是干预。可加 -grad ProbeLoss(A)^T(theta_B-theta_A) 作为优化器感知线性诊断，但不把已计算真实探测结果泄漏给待测预测器。
- 除非存在全局梯度裁剪等耦合，一步差异具有局部性；先验证局部实现与小规模完整双分支一致，再省内存。不得默认冻结其他行就等价于真实训练器；不保存全量逐样本梯度，不反复复制教师。

训练数据内部区分 update、信号 A、效用校准 B、最终审计 C。A/B/C 的正边应分离，负采样独立；同一正边换负例不足以证明跨用户迁移。稀疏物品无法满足分离时保留数量与原因，正角色不可识别项标 N/A，负角色结果可单报，不偷偷换成热门物品。

已有检查点曾使用训练边，故这只是新探测样本下的条件更新诊断，不是未见交互泛化。用于正式训练的选择信号必须预先定义训练内轮换/交叉拟合协议；所有对照共享相同划分和可用 BPR 数据，不让方法独占额外标签。现有 Validation 仅保留选模用途，Test 不参加设计、诊断和阈值选择。内层探测还应使用不会加载 Test 的独立读取路径。

## 5. 阶段顺序与预算

以下数字是决定研发规模的**计划上限**，不是已核验的运行参数或执行授权。每阶段在运行前单独声明资产、完整命令、硬资源上限、统计判据和记录目标；不得看到结果后扩样或自动推进。更换教师/初始化/优化器等属于新声明，不纳入本路线偷偷调优。

| 阶段 | 内容与范围 | 通过后的动作 |
|---|---|---|
| P0 资产与测量准备 | 先查 Sports 完整学生 checkpoint、optimizer、教师缓存与 manifest，区分 best/full 与 infer；确认冷/暖状态和中间状态真实可用。准备不读 Val/Test 的隔离诊断器。另行授权的非正式资源检查最多12个成对干预、10分钟，计时到限或显存风险即停止，不重试 | 锁定 P1 名单、训练探测分布、数值误差容限和预算。缺中期 checkpoint 不补训、不制造 early/mid/late 标签 |
| P1a 信号筛查 | 优先 Sports seed2022 的一个随机初始化训练所得 Full 状态和一个暖启动 Full 状态，实际资产须经 P0 确认；30物品（频率三层各10）×2模态×2状态×2固定 BPR context，最多240个干预。A/B/C探测池每角色每物品最多8条正边/三元组，独立负采样重复3次；按可用边降额，报告覆盖。首轮 U1，不训练 gate | 检查可重复性、理想化选择空间、简单信号能否转移。噪声主导或无可利用空间则停止 |
| P1b 有限步与复制 | 仅在 P1a 通过后，对预先抽定（非按效用挑选）的最多12物品做 U1/U5及Full背景删除边际。固定规则后在另两个已存在随机种子状态复制；不要求新增暖启动种子，缺失则保留单seed边界 | 只有样本外决策有用且不只限于一次线性近似，才进入短程策略 |
| P2 短程策略可行性 | 一条预定短程配对路线；先只用最低成本跨交互统计规则，无 MLP/attention。比较 BPR、固定Full、局部门控、聚合门控、统一降权、分层随机/打乱权重；若候选就是聚合门控，两者合并，不造两个同义方法 | 相比匹配对照有稳定增益且开销可接受，才准备完整训练；聚合已足够则收缩为实证/适配贡献 |
| P3 完整方法验证 | 最终规则冻结后按批准的预算执行 Sports，再做 Baby 迁移验证；目标各3学生种子，初始化/训练三元组/教师/选模对齐。先Validation，方法与超参冻结后才单独声明一次最终Test。每个具体run/cohort另授权，均用户手动 | 报告独立贡献是否有证据，不保证超越发布版PromptMM或暖启动BPR |

P1 三十物品是探索规模，不能支撑长尾普遍结论。两个 checkpoint 也不能证明全程状态规律。P0后若无法在上限内取得足够独立正边，缩小可声明范围，不自动补种子或重新训练。

P2 回放长度依据 P0实际吞吐及焦点再曝光频率在看P2效果前锁定；同时设步数与墙钟上限。等训练步用于科学归因，计入探测的总墙钟用于实际代价评估。资源未知时不承诺某小时内完成或开销固定比例。

## 6. 决策门与必要对照

### G0：测量可信

零干预两分支应在预定数值容限内一致；原checkpoint不变；真实/局部更新一致性合格；有限值、随机数与优化器身份可核对。低于数值分辨率的差异记不可识别。资源/实现硬条件失败与科学负结果分别记录。

### G1：有可重复、可选择的差异

分别报告物品/模态/状态间差异及独立探测块噪声，不只计算池化相关或普通独立样本ANOVA。分状态、模态和频率层分析，按物品成簇估计区间；共享用户依赖做敏感性检查，少数种子不作总体显著性保证。

保留比例主分析预定为每模态、频率层内50%，图文原权重不变。这是诊断对照设计，不是最终算法必须丢弃一半。B池测得效用用于理想化挑选，C池只评价；同时报告在同池选评的乐观结果但不得据此过门。比较同样数量随机选择与统一减半系数。联合短程效果仍需P2验证，单项排序/贪心选择不是全局最优或严格上界。

只有C池上的选择增益达到运行前确定的实际意义阈值且不被区间覆盖为明显不确定，才继续。若区间上界仍低于该阈值，可停止该配置；若区间过宽，记不确定并结束本预算，不把不显著说成等价。阈值在P0测量误差/可用样本明确后、查看P1效用前写入声明，不采用外来固定 rho、R² 或 Recall 门槛。

### G2：可由可用信息预测

同样的A池预算下比较局部dot/cos、正角色聚合、正负角色加权聚合、margin、频率、表示差异和常数规则。首轮不训练复杂预测器。主要终点是其C池所选集合收益及相对匹配随机/简单聚合的增益；Spearman、符号准确率仅辅助，并与多数类基线比较。按物品/状态留出，不能随机拆高度相关三元组冒充独立预测。

正负聚合超过局部只证明上下文估计有用；若要主张正负角色机制，应在相同总探测条数下比较正-only与正负混合，避免“多读数据”混淆。若提出更复杂候选，必须优于聚合梯度，否则不实现更多模块。状态排序反转本身不构成失败，应看当前状态输入能否正确识别。

### G3：有限步与组合决策有用

P1b检查U5、再曝光及Full背景；P2检查实际联合选择与排序指标。局部损失信号不保证Recall提升，U5也不是长期收益。若没有额外影响的短回放导致U5几乎等于U1，不据此过“持续性”门。

保留率、名义权重和实际更新量不是同一个预算：同模态/频率层打乱权重保留权重集合；统一降权匹配名义总权重；记录实际两分支参数差范数、累计差和总耗时。若结果被更新幅度差解释，再声明专门的幅度对照，不声称已同时精确匹配三者。所有梯度候选共享探测预算；另报告低成本基线的自然耗时。

通过的含义是：值得进入下一阶段，而非统计显著、独立创新或学位充分性已经成立。真正资源分配价值可以在无负效用时出现；这时不能写“消除负迁移”。

## 7. 预期效果：假设、目标与不保证事项

| 结果层级 | 合理预期/用途 | 不应承诺 |
|---|---|---|
| P0 | 得到可用状态、可测精度、显存/时间和真实可行的探测规模 | 已有全部训练阶段checkpoint、一定不复制状态或一定很便宜 |
| P1 | 工作假设：聚合信息可能比单交互稳定，正负角色可能出现不同效用；也可能效用很弱或只由简单梯度解释 | 必然存在大量负效用、必须跨状态排序一致、一定形成新算法 |
| 随机初始化主线 | 若通过，争取在相同初值/预算下提高Full，且胜过减量/打乱；预计是需要严格控制才能识别的增量，而非再次复制Full对BPR的巨大差值 | 任何有依据的固定提升百分比，或一定追平/超过PromptMM |
| 暖启动边界 | 若可识别无益监督，可能减少KD而保持接近BPR；须由新配对结果支持。暖启动不是优先追加完整训练的主战场 | 因减少KD就一定高于BPR，或单seed持平是等价保证 |
| 代价 | 推理仍用同规模ID表；新增成本主要在训练期，须计入所有探测与虚拟更新 | 新的线上加速、表压缩、总训练更快或更少调参 |

对最终性能给三种可接受的科学结局：

1. **机制与方法均成立**：独立交互预测、有限步及等预算选择均通过，进一步验证跨数据集效果；再主张有边界的方法贡献。
2. **现象成立、简单聚合足够**：保留监督效用的机制/实证研究，承认算法是已有梯度选择的适配；不通过加模块追求新颖性。
3. **测量、预测或行动价值不成立/证据不足**：终止当前选择算法投入，保留固定蒸馏结果和负结果。不能因此重跑旧Test、删除结果或保证另一个新题可行。
