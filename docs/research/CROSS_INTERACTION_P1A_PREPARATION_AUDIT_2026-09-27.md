## 独立训练集覆盖检查

在所有非零频物品按频次与 ID 固定排序后的三层内，按预定 seed 从**两个 context 均出现**且非 P0 焦点 1494/1744/1646 的候选抽最多 10 项；这是明确的双 context 曝光条件样本，不代表同层全部物品。两个 context 正物品交集 111 项；满足排除的低/中/高层候选分别 **3/11/97**，最终固定选择 **3/10/10 = 23 项**，低层缺 **7 项**，不补热门物品。A/B/C 正边严格互斥；所选 23 项中 A/B 均有正角色边，C 有 **1 项正角色 N/A**。每池正边少于 8 条的所选物品都是 **17/23**；即使存在边，按唯一正边估计的可用样本也很小。负角色合法上下文数单独记录，不用于填正角色空缺。

结果快照保存在 `exp/cross_interaction/p1a_coverage_seed31027_v1/coverage.json`，SHA256 `9aeb3a9005131292cc0ef02efdf783126c3f955c982076dcf7ad5ff8cab51f7c`；源模块 SHA256 `b89bb1682b17c3ade5935b35f984f4ed32c424e48297ce3e3979feda813c1816`。它包含两批三元组、逐项频次/出现次数、A/B/C 正边及负角色可用上下文和层内短缺，是**覆盖快照，尚非可执行探测计划**。已有 P0 plan SHA256 `11130dd5cc71ee2da45a485bb04c3946a6d5e9f310940019cc219fe1d1557393`；新选中焦点与旧三项不重合，所选项目的全部新 C 正边与 P0 当次实际 update/探测正边无重合。旧 P0 C 的效用绝不复用作新 C 结果；共享原训练历史仍使这不是未见交互泛化。
