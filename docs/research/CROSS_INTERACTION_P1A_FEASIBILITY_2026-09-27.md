## 2. 目标量、探测隔离与可识别范围

一次干预从同一状态、同一 AdamW 参数/动量/step、同一 RNG 和同一 BPR batch 出发：A 做 BPR 更新；B 做 BPR 加**一个**焦点物品模态 KD 的原 Full 系数更新。图像 `0.3/1.3`、文本 `0.09/1.3`，按原 batch×64 归约，保留该物品在 batch 中的所有正例出现；其它项不重新归一化。U1 是更新后同一训练内探测分布上 `loss_A−loss_B`，分正物品角色与协议负候选角色报告，并按原 user-uniform、user-positive-uniform、全训练正例补集 negative-uniform 的真实概率合成。测量采用 P0 已合成验证的只读高精度损失差；原 fp32 模型、梯度及 AdamW 更新不改。它是**既有训练边上的条件更新诊断**，不是未见交互泛化、Validation/Test 排名或最终 Recall 效果。

新 P1a 设计需在看任何 P1a 效用前封存 train-only 的物品名单、频率层、两个固定 BPR context、更新批次、A/B/C 正边分配、三组负采样种子及完整计划 hash。P0 的三项焦点物品和已曝光 C 不参加新的独立 C；不得从 P0 C 的符号挑 P1a 名单。A 只产生可用信号，B 仅用于效用校准/理想化选择，C 在所有规则与阈值冻结后一次性审计。A/B/C 正边互斥、负采样独立；同一训练正边换负例不能算跨用户迁移。记录共享用户并做敏感性分析。代码必须只读取 `train_mat`，拒绝 Validation/Test 文件与排名入口；教师只复用经声明的缓存，零教师前向。

训练频次三层各最多 10 个预抽物品、两模态、两状态、两个 context 是**240 个干预对的计划上限**，不是已核验可执行规模。物品按冻结的频率层及 seed 从候选抽取；缺边时记录原抽中物品及原因，降额或正角色 N/A，不替换成有利的热门物品。训练矩阵共 18,357 物品，其中 5 个零度、2,050 个度数 1–3，只有 16,302 个至少具备四池分配的边；即使度数≥4，也未必每个 A/B/C 池有足够的**不同正边**。每物品/角色/池至多 8 个独立正边或基础三元组；预定 3 次独立抽样重复。正角色固定 `p=i` 并重抽协议负物品；负角色固定 `n=i`，此时不存在可重抽的焦点负物品，而应重抽合法 `(u,p)` 上下文。分别保留重复及唯一边计数、权重与有效样本量。若正角色无法分离，负角色可以单报但不填补正角色空缺。P0 的受限 update 池与原全量采样器不同，P1a 必须明确并保持 update 分布；探测权重相应按声明的目标分布计算，不能随意把两角色 50:50 平均。

## 3. 预先分析与判定

先分状态、模态、频率层、context 和角色列出效用分布、池间变化、覆盖率与数值容限；不把 240 对或三次负样本当成 240 个独立物品。以物品为簇构造区间，报告共享用户依赖的敏感性、跨 context 一致性和样本量/有效样本量。区间计算方式、随机种子、缺失项处理与分析脚本都应在运行声明中冻结。两个状态、一个种子不支持总体显著性结论。

G1 的**诊断性**主比较：每一状态×模态×频率层内，以 B 池效用选 50% 项，固定原名义 KD 系数；只在 C 池评价选择对等数量分层随机集合与统一半系数对照的收益差。均匀半系数需要真实配对 AdamW 干预，不能把全系数 U1 除以二充当测量。同池选择/评价仅报告乐观偏差，不过门。逐项 U1 排序不是同时开启这些项的联合效果，也非严格 oracle 上界。若单项诊断无法支持实际集合对照，G1 保持未判定，不能用加和近似宣称已通过。

G2 使用相同 A 探测预算，预先固定常数、局部 dot/cos、正角色聚合、同预算正负角色聚合、margin、频率和表示差异等简单规则；不得把 B/C 的真实效用或探测后更新差当成预测器输入。规则在 B 选定/校准，C 评价所选集合对分层随机及简单聚合的差；符号准确率/Spearman 为辅助，须与多数类基线比较。按物品/状态隔离拟合或调参，不随机拆相关三元组。G3 的 U5、Full 背景删除和联合短程效果均属后续阶段，P1a 不执行。

**尚未冻结的硬门槛：**C 上“实际有意义”的最小收益差必须在首次 P1a 效用可见前，用训练损失单位、应用价值和可实现的测量/样本精度定出具体数值及区间规则；不能从三个 P0 项的微小 U1 或 P1 结果事后选阈值，也不能借用固定 `rho`、`R²`、Recall +0.005。当前缺乏成本/效用换算依据，故不伪造数值。预注册运行声明须写明：若 C 的区间下界高于该阈值且相对匹配对照的方向一致，才可判 G1/G2 值得后续研究；若区间上界低于阈值，停止该配置；若覆盖阈值或覆盖不足，记不确定并在原预算结束，不自动扩样。数值分辨、G1、G2、G3 分开验收；科学低效用不是执行失败。

## 4. 资源与停止规则（计划上限，非启动配置）

240 个非零对意味着至多 480 次从同一状态出发的**独立单步**优化器更新。建议每状态×context 一个零干预对，另外 4 对/8 步，合计最多 **244 对/488 步**；这不含模型加载、A 信号梯度、CPU 高精度探测和对照系数真实配对更新。若按每个角色/池 8 个基础样本×3 次负采样计，非零对至多 `240×3池×2角色×8×3=34,560` 个三元组，每个 A/B 更新后都要评价，最多 69,120 次分支三元组读数；零对及半系数对照另计。覆盖不足只降低实际数目，不允许改变抽样规则补齐。必须在独立准备阶段完成 train-only 覆盖计算、内存/耗时估算、半系数及零对照的完整计费，形成有限墙钟、显存、CPU 线程、输出体积和失败处理上限，不能把 P0 的 7 对/4.86 秒线性外推为 P1a 保证。

运行前硬停：任何身份/缓存不一致、非有限参数/动量或探测、零对照不一致、越界资源、held-out 读取、源未提交/不干净、输出目录非独占即停止并保留部分产物；一次声明只允许一次用户手动启动，无自动重试/扩样。低或负的有效效用正常保存；即使 G1/G2 不过也不回滚 P0/历史结果。P1a 结果写新的 `docs/research/CROSS_INTERACTION_P1_AUDIT.md` 与 `TRAINING_LOG.md`，更新实验族和生成导航；旧 18 格正式矩阵及论文主张无新正式证据时保持原样。当前文档**既非运行声明，也非执行许可**。

## 5. 完成启动声明前还缺什么

1. 闭合冷状态语义缓存身份，或明确批准改变目标范围/统一缓存定义；两种选择都须写明比较含义，不能默认等同历史冷 Full。
2. 用 train-only 独立计划检查预抽各层/角色的正边与用户覆盖、P0 暴露排除、独立负采样和概率权重；在看新效用前封存计划及 hash。
3. 给出有依据的 C 池实用差值阈值、区间/敏感性实现、半系数真实对照的完整成本，并通过合成协议测试。随后才可按[RUN_CLOSEOUT](../experiments/RUN_CLOSEOUT.md)写单次手动运行声明与唯一命令。
