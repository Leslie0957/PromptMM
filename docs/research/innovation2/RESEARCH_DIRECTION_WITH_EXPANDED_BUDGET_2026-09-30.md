# 第二项路线重评：时间充裕，按证据决定投入

2026-09-30。起点提交2ddf269；依据[论文路线](../../../THESIS_ROADMAP.md)、[原候选评审](INDEPENDENT_CANDIDATE_REVIEW_2026-09-30.md)和[具体映射提案](NEW_ITEM_METHOD_PROPOSAL_2026-09-30.md)。用户明确：有意义的研究可以投入一个月，前提是方向正确。本次完成问题层面的重评和首阶段诊断设计思路，未实现、重建或运行。

**当前判断：新物品内容接入仍值得做问题层面的立项诊断；被否决的评分几何岭回归继续只作为基线。先回答“多模态教师的额外能力能否迁移到真正未见物品，以及迁移受限在哪里”，再决定新方法。尚不能宣布已走在正确道路上，更不能宣布已有第二算法。**

## 1. 预算澄清后，研究顺序怎样改变

“一个月也可以”说明不应以数小时的重建成本淘汰有价值的问题，不等于已冻结720 GPU小时或授权连续训练一个月。上一提案中的六小时只是讨论草案，不再作为路线筛选依据；它不是已经消耗的预算、执行上限或算法价值判据。

上一阶段否决的确切对象是用户几何线性映射：评分监督和求解都可归约为已有方法。这个否决有效，但由此停止整个冷启动问题会超出证据。最新决策是重新开放**问题诊断**，没有撤销旧结果，没有把旧机制重新批准为新算法。

需要把三项判断分开：

1. 问题存在：可信的未见物品任务中，当前方法确有可测的能力缺口，且符合多模态迁移/效率主题。
2. 存在可学习的改进信号：同输入和容量下，迁移能够带来收益，或强基线失败呈现可复核的具体机制；不是oracle互补或教师自身更强就够了。
3. 方法有独立增量：针对该机制的新操作，超过既有对齐、回归、排名训练、校准等解释，在公平预算下有价值。

可以在第1、2项尚未完全解决时做有信息量的基线诊断；无需先凭空发明并“证明新颖”的模块。第1、2项通过仍不等于第3项通过。较长预算用于建立证据、强基线、必要复现和独立确认，不能代替这三项判断。

## 2. 重排路线时保留哪些证据

| 问题 | 时间放宽后改变的部分 | 仍未解决的科学障碍 | 本次决定 |
|---|---|---|---|
| 未见物品的多模态知识迁移 | 可认真考虑合法教师、内容变换器和强基线的重建成本 | 真实迁移增量未测；近邻很强；已有表不满足新信息边界 | 首选问题诊断，不批准新算法 |
| 旧低频组TopK分配 | 可以负担更严谨的训练内留出和标准排名基线 | U收敛/收益小、H/R仍unresolved；模态必要性未证；排名校准已有方法 | 维持备选，不因预算增加重开旧配方 |
| 持续知识更新 | 教师周期刷新比较的计算成本可讨论 | 时间资产及漂移未证；随机分批不能证明真实动态任务 | 保留问题，当前不切换，不获取新数据 |
| 表压缩/检索加速 | 有时间做真实预算曲线 | 当前64维表缺乏明确部署限制；已有压缩加排名蒸馏 | 不因可跑一个月而人为制造限制 |

依据仍是[原评审](INDEPENDENT_CANDIDATE_REVIEW_2026-09-30.md)中的保存结果，不把时间放宽写成这些负结果失效。新物品问题优先，来自现行ID查表缺少内容接入路径、与第一项任务区分清楚；**不是因为已有结果证明它能赢**。

## 3. 新核查的近邻进一步限定了可做的主张

| 原始来源、核查深度 | 与当前问题直接相关的内容 | 对我们的要求 |
|---|---|---|
| [ALDI](https://web.comp.polyu.edu.hk/xiaohuang/docs/2023SIGIR_Feiran.pdf)，上一阶段已读方法正文 | 行为教师到内容学生的评分/排序/识别对齐和教师可靠性调节 | 内容生成、可信度加权、冷热对齐不能单独作新增点 |
| [SiBraR](https://arxiv.org/html/2409.17864v1)，上一阶段已读方法正文 | 多模态共享编码与冷启动 | 需要认真对照内容推荐强基线，不能只对比随机新ID |
| [Inherited Popularity Bias，RecSys2025](https://arxiv.org/html/2510.11402v1)，本次读§3–4.2 | 冷启动生成器可能继承暖教师的流行度偏差；通过向量幅值向暖输出均值收缩作简单后处理 | 加入幅值/冷热分数校准作为解释控制；“教师偏差会迁移”不是我们的首次发现 |
| [DiffCold，2026](https://arxiv.org/html/2606.12245v1)，本次读§3及效率分析 | 条件扩散、暖邻居初始化、模拟接入对齐、冷热联合训练；推理多步生成 | 不把扩散、邻居、模拟冷启动对齐或效率叙述本身当新增点；必要时作为完整方法对照 |
| [Shallow-RHS，2026预印本](https://arxiv.org/html/2606.06225v1)，本次读任务/方法概述与§4 | 内容侧独立向量、用户时序历史及生产数据的内容覆盖改进 | 独立入库向量已有先例；私有时序/用户属性与本仓库不同，不能承诺直接公平复现 |
| [Cold-Starts in Generative Recommendation，2026](https://arxiv.org/html/2603.29845v1)，本次读研究设置与§5.2–5.4 | 在所研究的生成式模型中，扩大模型未消除未见物品差距，并展示标识/训练策略混杂问题 | 支持控制容量和协议；不能推广成所有冷启动模型的普遍定理 |
| [Privileged Graph Distillation，2021](https://arxiv.org/abs/2105.14975)，本次只读作者摘要 | 暖协同特权信息到无交互属性学生的蒸馏 | “迁移可用协同知识”不是未被研究的概念 |

这些是定向排重与实验设计约束，不是穷尽文献检索或独立复现。论文报告的收益不是本项目的证据。Shallow-RHS的生产实验包含多项覆盖/系统改变，不据此把某一个模块的独立作用或新颖性认证给本项目。DiffCold此处不被假定必须比小MLP昂贵，其整体效率也须同协议实测。

新线索最有用的地方是：除了内容是否够用，还要区分**教师中哪些信息实际能迁移、跨目录分数尺度是否失配、以及内容本身是否缺信号**。这三类因素都已有相关研究，不先将它们组合命名为我们的算法。

## 4. 首阶段真正要回答的问题

研究问题暂定为：

> 在教师与所有训练资产均未见新物品交互/内容的条件下，相同容量的内容接入模型能否利用多模态教师，获得超过直接暖Train学习和纯协同教师迁移的暖冷混合目录收益？若没有，证据更符合信号不足、目标/容量不匹配，还是分数校准的解释？

教师不看新内容是任务内边界；冻结外部特征编码器的预训练暴露仍未知，需限定结论。首阶段给定预提取图文特征，不声称原始图文端到端接入成本。

以下是假设，不是事实：

- H1：暖任务上较强的多模态教师，其额外能力不一定能被内容学生迁移到未见身份。更强教师不自动等于更好监督。
- H2：映射对教师目标的拟合变化与混合目录排名变化可能不同；已有评分对齐也可能存在任务/协议限制，但尚未测到。
- H3：只修正生成向量幅值或冷分支尺度，可能解释表面上的“迁移改进”；若如此，新增复杂机制不必要。

一个低结果不能定位原因。首阶段必须允许“尚不能判定”，检查教师质量、收敛、数据量和评价精度后才作解释，不能把负结果一律归为内容不可预测。

## 5. 一次可区分解释的诊断设计骨架

这是用于下一阶段冻结协议的设计，不是现成运行声明。尚未选择ID集合、创建split/profile、实现loader或写启动命令。

### 信息边界

首选利用现有Sports原Train来构造新任务，避免立即依赖新数据。只用原Train可见物品身份按预定、与效果无关的规则划分暖集合W和冷开发集合C_dev，另锁定C_lock。暖内部再留出教师/训练选择交互。用户须在暖训练中有交互；用户冷启动另列，不混入主任务。集合比例、随机源、用户筛选、重复交互和暖留出规则由协议准备阶段事前冻结，不按新指标改划分。

- 所有上游教师图、用户/物品统计、PCA/ICA及内容训练都只来自暖Train；不能从旧完整教师删行后充当合法资产。
- 两个教师来自同一暖任务：纯协同T_CF和多模态T_MM。各自只在暖内部选择集选模。尽量采用相同图/维度/训练规则，剩余结构差异明确报告；不是声称两者总计算相同。
- 冷开发内容只在冻结变换器下接入；冷开发交互只供评价/事前限定的选模，不作梯度目标、频次或邻居依据。C_lock的特征与标签不用于本诊断训练、变换拟合、候选池或选模；以后若读取其标签属于确认评价，需要单独冻结与授权，不能以“不是旧Test”规避评价门槛。
- 本诊断主候选目录是W∪C_dev，屏蔽用户暖Train已见物品；不是只在冷目录内挑Top20。旧Val/Test路径不加载、不用于集合或阈值选择。
- 原Train过去已用于本项目研究；新划分只建立新的模型信息边界，不抹除研究者对该数据集的先验知识。本诊断属于探索，不能称全新独立数据证据。

### 最小核心对照

为使“教师监督的增量”可解释，先固定共同的用户空间P_CF及暖物品表Q_CF。所有核心内容映射都输出同维向量，服务时暖物品仍用Q_CF；各组用户、暖分数、输入及候选池一致。

| 核心对照 | 训练目标/区别 | 可以排除的简单解释 |
|---|---|---|
| R：普通岭回归 | 仅由暖内容预测Q_CF，含截距 | 最简单的内容映射已经足够 |
| V：小MLP向量回归 | 同输入，暖Q_CF目标 | 收益仅来自线性变非线性 |
| D：同容量小MLP直接暖Train排序 | P_CF固定，无额外教师评分目标 | 迁移不如直接任务学习 |
| K_CF：同一MLP，D加T_CF评分监督 | 固定采样/规则/容量 | 通用KD或协同监督已经解释效果 |
| K_MM：同一MLP，D加T_MM评分监督 | 与K_CF仅教师目标不同，其余规则一致 | 是否真的需要多模态教师的额外监督 |

D不是完全“无教师”系统：它共享协同锚点P_CF，只是没有额外蒸馏目标。不能用它证明从零训练的内容模型不如教师迁移。共同冻结表的结果也只支持这个兼容设定，不能代表所有端到端冷启动方法。

T_CF与T_MM存在坐标旋转和用户表差异，因此K_MM用合法暖样本上的**教师评分**，不能把Q_MM向量直接塞进P_CF空间。采样用户/物品的方式、教师尺度处理和KD权重须事前冻结，来源限暖训练统计；不能把坐标/分数未对齐导致的退化解释为内容信号不足。

核心对照还需两个便宜解释控制：用户暖历史的内容KNN参考，以及固定规则的冷分支全局分数校准/已有幅值收缩。KNN是完整参考方法，不属于相同P_CF的容量隔离比较。校准必须使用各组相同的开发选择预算并报告原始与校准后结果，不能只帮某个KD组调参。不能用真实冷流行度指导校准。

ALDI/SiBraR是进入算法验证前必须认真面对的完整方法参考；若首诊断包含受冻结空间限制的适配，要清楚标注，不能替代原算法复现。后续主张涉及生成分布/多步接入时，再纳入DiffCold等直接近邻。第一阶段不声称胜过这些未完成的强对照。

### 观察什么

- 在同一个混合目录中，报告总体及暖/冷正例的Recall@20、NDCG@20、命中数、分母和有正例用户数；各组都使用同一排名。不要把两个不同候选池的指标拼成总体，也不要无条件平均暖/冷宏Recall。
- 报告冷目录单独排名作为辅助，比较加入暖目录后的变化；这只是诊断尺度竞争，不能用辅助指标替代主质量。
- 教师目标拟合只在合法暖内容目标上核查；暖内部映射留出只能称暖目标泛化辅助诊断。真正冷物品没有合法的行为教师向量/评分目标，不从旧教师取“冷真值”，不构造读过冷交互的oracle教师。
- 记录新物品向量幅值、跨组分数、曝光集中度以及简单校准效果；这些是关联/干预线索，不是没有曝光日志时的因果去偏证明。
- 暖任务T_MM优于T_CF只说明教师端能力差；K_MM相对K_CF/D的结果才涉及本设定的可迁移价值。优化与拟合不足必须先查明，不能拿一个不足训练的K_MM作反证。
- 记录教师重建、表示/缓存准备、学生训练、评价、给定特征后的入库和服务成本；额外离线花费可以接受，仍需明确服务环节的质量/预算价值。

第一阶段可以是一个预定seed的机会诊断，而不是一开始把每个方法跑三seed。一个seed的结果不证明稳定性；支持后再以新的明确阶段做配对重复/其他数据确认。扩大试验数量必须服务于尚未排除的解释。

## 6. 结果怎样决定是否继续

| 诊断结果 | 合理结论 | 后续方向 |
|---|---|---|
| K_MM相对K_CF/D在合法混合目录中有可重复收益 | 本设定存在多模态教师的可迁移信号 | 定位收益/损失机制，核查既有强方法；仍未认证算法新增 |
| 只有向量拟合变好，混合排名不变/下降 | 可能有目标或校准错位，不能单独归因 | 用预定简单评分/校准控制检验；不立刻加模块 |
| 简单分数/幅值修正已解释收益 | 标准校准足以解释当前现象 | 保留有价值的基线结果，停止把它包装成第二算法 |
| K_MM不优于K_CF/D，且训练/教师质量检查有效 | 这一资产和容量下额外多模态教师监督未展示价值 | 暂停该迁移设定；不是证明全体冷启动无解 |
| 简单映射已达到既有强方法水平 | 当前瓶颈可能不值得复杂化 | 查明成本贡献能否独立成立；不自动降低用户的算法要求 |
| 内容KNN/直接学习较好，而迁移组弱 | 教师监督可能并非必要，或适配有问题 | 先检查目标/尺度和公平性；若无独立迁移问题则重新选题 |
| 样本过少、置信区间宽、优化不充分、强参考缺失 | 未判定 | 补正识别所必需的信息；不强判成功，也不依据低均值回滚 |

效果门槛、暖质量容忍量、选择次数和置信区间规则尚未冻结，必须在任何真实结果出现前决定，不继承旧H阈值，不按首诊断结果改停止线。不存在一个事先保证“正确路线”的分数；继续的依据应是可复核的现象和逐步排除的替代解释。

## 7. 一个月应投入到什么地方

投入顺序是：合法资产与强基线 → 可复核瓶颈 → 针对性机制及不可约性检查 → 配对控制/多seed/多数据确认 → 冻结结论与成本。每一箭头都有证据门槛，不是自动执行的月度任务清单。

可接受重建教师、必要复现和失败试验的代价，但不设“跑够一个月就成功”的目标。资源预算应由实际设备容量、每阶段有效问题和预检测量来制定；目前没有足够证据承诺小时数、显存或完成日期。上一份六小时草案不再约束本问题诊断，先前岭回归算法否决仍成立。

当前新数据范围没有精确确认，本次选用现有数据的设计即可推进；不会把这个未知项反复退给用户作为停止分析的理由。若现有原Train不能形成有信息量且边界可信的诊断，再说明缺什么数据、代价及收益，提出具体的新数据请求。

## 8. 唯一下一阶段

**准备并冻结一次Sports未见物品“多模态教师可迁移性与混合目录瓶颈诊断”的可执行协议。** 先确定合法split、教师/变换器重建范围、核心对照、评价与选择规则、判断门槛、记录路由、资源上限及明确命令；方案可审查后才进入具体执行授权。不是重跑被否决的算法，也不同时启动持续更新/旧低频/压缩路线。

本次只读文档与原始论文，追加研究记录并更新当前导航；没有载入真实数据或模型，没有创建新split、变换器、教师、实验profile、产物目录或运行声明，Test访问为零。[论文总体目标](../../../THESIS_ROADMAP.md)、第一项、原始候选评审/提案与所有结果均保留。
