# 最小排序监督因果对照：准备方案 v1.0

2026-09-29。状态：**协议草案已固定；尚未实现、资源预检、声明或运行。** 本次完成方案准备，不授权训练。用户后续明确委托准备/执行时遵守AGENTS的一阶段、一次启动规则。第一项暂停扩展；[总体路线](../../../THESIS_ROADMAP.md)不变。

## 1. 目的、已有事实与反对解释

[独立排序缺口审计](RANKING_GAP_INDEPENDENT_AUDIT_2026-09-29.md)发现：教师初始化+BPR（T0）有教师独有命中G≈.0072–.0079，但学生独有命中更多，三个seed教师整体Recall都略低。G是借助Validation标签识别的机会，不是可实现提升。约99%的G集中于高频物品，不支持把本实验包装成长尾方案。

本轮问题：在完全相同的教师表初值、BPR批次、优化器与更新预算下，加入最简单的教师候选排序分布约束，能否带来净推荐收益？若能，是否只是初始表示约束或简单师生混合即可解释？“因果对照”仅指固定配置下增加训练目标的干预，不意味着能唯一归因于语义/知识类型。

不设计门控、自适应权重或新模块；不追求新颖损失。本轮只用于决定是否值得继续研究，不认证第二创新点。负结果仅约束本配方，不证明所有排序蒸馏无效。

## 2. 最小比较集合

仅Sports、seed2022（事前指定沿用锚，不挑最有利seed），三个新训练臂串行执行，另一个固定混合评价：

| ID | 初值与目标 | 要排除/检验的解释 |
|---|---|---|
| B | 教师最终用户/物品表；BPR | 同期配对核心基线；不能只引用旧T0而省略实现回归 |
| R | 相同初值；BPR + 1.0×候选分布KL | 最简单排序保持是否带来净收益 |
| A | 相同初值；BPR + 1.0×归一化初值距离 | 是否普通初值约束就足够 |
| M | 不训练；B末轮与冻结教师分数各0.5 | 是否简单混合就足够，无混合系数搜索 |

教师不微调；学生只有两张64维ID表，内积打分。三臂均关闭第一项图文方向KD和用户KD，从共同教师初值重新开始，不能从旧T0 final继续。AdamW每臂空moments、lr=6e-5、wd=.01、betas=(.9,.999)、eps=1e-8，其他细节严格复用原初始化实验。训练顺序B→R→A固定；不是等墙钟比较，成本另报。

三臂300轮，每轮214步、batch1024，64200步/臂。使用原seed2022的同一完整triplet tape，不更换或重新采样BPR负例。R候选独立RNG，绝不能改变BPR轨迹或A/B随机流。旧T0作为数值回归参照，不作为第四条新训练臂。

## 3. 固定教师候选与排序约束（通用诊断目标）

每个Train有交互的用户u，候选C_u为64件互不重复物品：教师全物品评分中排除该用户Train已知项后的top32，另从剩余非Train、非top32物品均匀无放回取32件。精确同分按较小item ID；NumPy default_rng(20260930)，按user_id升序生成，记录版本和最终候选SHA。全部只用Train与教师表，生成时禁止加载Val/Test或ranking-gap逐用户产物。未观测不是负偏好；两类候选均不标记真实正负。

候选与教师分数固定一次，不随epoch/学生刷新。每个训练三元组的用户对应同一C_u；重复用户按三元组出现次数加权，明确承认活跃用户偏重。教师全候选打分准备成本单列，禁止缓存全用户×全物品矩阵。

令教师/学生分数为s_T(u,i)、s_S(u,i)。对每用户64个教师候选分数计算mu_u和总体标准差sigma_u，取a_u=max(sigma_u,1e-6)。定义q_T=softmax((s_T-mu_u)/a_u)，q_S=softmax((s_S-mu_u)/a_u)，温度固定1。a_u、mu_u和q_T全部冻结，不使用学生统计量归一化。

L_rank = batch用户出现次数上的mean[sum_i q_T(u,i)×(log q_T(u,i)−log q_S(u,i))]。

使用log_softmax稳定计算，先按候选求和再按batch平均，不额外除以64。教师detach。R总目标BPR+L_rank。初始学生等于教师，KL及其梯度应近零；这不是错误，也不能用初始梯度比做权重标定。训练只抑制此后候选分布的偏离，仍不能证明“找出了哪些教师命中值得保留”。

KL是标准分布约束，既依赖次序也依赖归一化分数间距，不称纯次序新损失，不称完整复现某篇排序蒸馏论文。固定64、top32/随机32、权重1只是单次筛查配置，未充分调优。

## 4. 初值约束与混合评分

令E_U^0、E_I^0为共同初值，c_U=max(mean全部初始用户坐标平方,1e-12)，c_I同理。A每个三元组(u,p,n)的约束：

L_anchor = mean_batch[(mean_dim(E_U[u]−E_U^0[u])²/c_U + mean_dim(E_I[p]−E_I^0[p])²/c_I + mean_dim(E_I[n]−E_I^0[n])²/c_I)/3]。

平方指逐坐标差的平方，不能实现成均值后平方。A目标BPR+L_anchor，冻结初值。它保持用户/正负物品原坐标，旨在提供简单正则化对照。R/A虽然权重都为1，**并不匹配梯度、约束剂量或额外物品访问**；不能以R>A唯一证明排序信息机制。这是最小筛查的明确局限，若进入机制研究再处理，不在本轮增臂。

M仅用B第300轮：s_M=.5s_B+.5s_T，全物品、排除Train、原top20协议。不根据Val调权或归一化。原始分数量纲相同但范数可能漂移，需报告漂移，单个固定混合失败不能排除所有集成。

M不额外训练，但通常保留两套表；亦可拼接为128维内积实现。因此不得将M与64维单表声称同存储/同评分成本。R若只追平M，在更小部署表上可能有价值，但须后续独立成本证明，本轮只能标记未决，不能宣布无损压缩。

## 6. 继续与停止：固定单seed描述性标准

定义d_R=R300−B300，d_A=A300−B300，d_M=M−B300，全部绝对Recall。实用筛查δ=.001；简单方案差距阈值epsilon=.0002（均为预先资源决策，不是显著性/等价/非劣标准）。

- 硬验收失败：technical_fail/partial，保留并停止；不做科学优劣结论，不重试。
- d_R<δ：本配方screen_stop，不追加权重/候选搜索，不因此否定排序蒸馏普遍价值。
- d_R≥δ但R−max(A,M)<epsilon：simple_alternative_or_unresolved，可能有净收益，但没有显示区别于简单替代的足够增量。M成本不同的价值留待审计，不自动转写成效率成功。
- d_R≥δ且R−max(A,M)≥epsilon：candidate_for_replication，仅允许建议另一seed独立复核和更严格机制控制，不自动运行。

所有分支在本cohort结束后交独立审计。不得因某子组/best/NDCG更好而替换主终点；若NDCG下降或新增成本大，明确记录，达到Recall门槛不等于无条件值得继续。没有期望必胜幅度，合理结果包括零收益/负收益。

## 8. 与已有工作的关系

排序蒸馏本身已有直接工作：[Ranking Distillation](https://arxiv.org/abs/1809.07428)、[Collaborative Distillation](https://arxiv.org/abs/1911.05276)。师生互补与排名差异也已有[Bidirectional Distillation](https://arxiv.org/abs/2106.02870)、[Dual Correction](https://arxiv.org/abs/2109.03459)等近邻。

此次仅核查论文摘要层面的邻近性，不是穷尽新颖性检索，也不声称上述通用KL完全复现它们。即使本轮成功，“加排序KL”“保留互补信息”本身不能直接作为独立创新；需另行全文比较并证明具体机制差异。本轮没有新的算法名称。
