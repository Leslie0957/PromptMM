# 模态邻居有效性诊断 v1：准备协议

状态：2026-09-29，仅协议准备完成；尚无实现、资源实测或诊断结果，不是运行声明。本页不授权训练、Test、自动重试或下一阶段。

## 1. 问题与证据边界

唯一问题：对 Sports 低频物品，冻结教师图像/文本分支中的相似邻居，是否比**训练频次构成完全相同的随机邻居**更常出现在该物品 Validation 用户的 Train 历史中？

已有[稀疏统计](SPARSE_ITEM_ASSESSMENT_RESULTS.md)显示师生低频命中都少，不能归因为简化损伤，也不支持教师拥有现成的尾部排序优势。本诊断检查另一种信息来源——相似物品的交互关联；不是推荐效果实验、因果增益实验或新算法。

教师分支表示含完整 Train 的学习信息，不是原始图文特征。不得事后拆 Train 并声称对教师独立留出。这里使用原有 Validation 正例作为关联目标，但教师选模及多次探索已使用过 Validation，因此只是**复用 Validation 的探索性筛查**，不是独立确认。正结果不能唯一归因图文语义，亦不能证明超越协同邻居。后续若有算法价值，仍须与协同/简单共享基线比较。

## 3. 查询物品、候选与邻居

- Train 二值化去重，d(i)=不同训练用户数。沿用原统计按 `(d(i), item_id)` 升序分三等份，低组6119物品（频次0–5）。保留频次5跨边界按ID分组的限制，不另找分箱。
- 查询集合为全部低组物品，**不能先用 Validation 选查询物品**。候选为 d(j)>0 且两个模态向量均有限、非零的物品；两模态共用候选与查询有效性规则。排除自身。记录每种排除原因和覆盖比例；非有限值视为硬失败，零向量只按事前规则排除。
- 每模态独立 L2 归一化、float64 CPU 分块点积、余弦前 k=20；同分按物品ID升序。不加融合模态、相似度阈值、邻居权重、互近邻或k扫描。有效候选不足20则停止；输出邻居ID和相似度，不输出全量相似矩阵。
- d(i)=0 的查询可构图，但单独报告；不能据最多5个零频物品宣称冷启动效果。主表保留原低组定义，并补充剔除零频目标后的同一统计，不据此改主判定。

## 4. 精确频次随机对照

对每个查询i、模态m，记录20个真实邻居的频次多重集。对其中每个频次d，从同一候选集合中满足 d(j)=d 且 j!=i 的池中，无放回抽取所需数量。各频次池不相交，因此整组无重复。不得排除真实邻居；它们也是零假设的合法成员，强行排除会改变对照。

固定100次随机重复，NumPy PCG64，基础seed=20260929，按 `(重复号, 模态编号 image=0/text=1, 查询ID, 频次)` 用 SeedSequence 派生流，不依赖循环并行顺序。不增加重复数或更换种子以改变结论。

每个随机组精确匹配k、自身排除、候选资格和频次直方图；不匹配用户身份或交互共现，因为那正是待测信号。池大小等于所需数时该块固定，不能粗化频次来制造随机性。报告每个查询可变槽位比例（该频次池大小>所需数的槽位/k）、真实/随机重合率及候选池大小分布。

有效支持检查：至少80%的可评价低频正例对应查询，其可变槽位比例>=0.8；否则总体标记 `inconclusive_matching_support`。这个80%是操作性覆盖门槛，不是统计标准。固定块依然保留在主估计中，禁止只报容易匹配的子集。

## 5. 关联效用与汇总

令 H_u 为用户u的 Train 物品集合，E为有效低组查询的 Validation 正例集合；Train/Validation重叠、越界或重复标签协议异常必须显式检查，不默默修数据。

对每条 (u,i)，定义 a_m(u,i)=1[ N_m(i) 与 H_u 有交集 ]。这是**邻居历史关联率**，不是 Recall@20：未产生用户候选排序，也未选择推荐阈值。随机对照以相同(u,i)、同一H_u计算。

主效用：A_m=mean_E a_m；A_null 为100个随机组关联率的均值；Delta_m=A_m-A_null（百分点），同时报告比值 A_m/A_null（零分母写NA，不加平滑）。零历史用户保留且记0。另报：交集数/k、每目标物品先平均再宏平均、各目标频次0/1/2/3/4/5支持量与Delta；这些都是固定补充，不择优选子组。

数据完整性表：低组总查询数、有效查询数、Validation正例数/用户数/目标数、被排除的正例数及比例、不同目标的支持分布、匹配可变性。既有6347低组正例只是全量参照，过滤后分母必须如实报告；有效覆盖低于95%标记 `inconclusive_coverage`。

不确定性：固定100随机组的均值/标准差/最小最大值；以用户为簇，对每用户全部正例的真实减随机均值贡献做1000次bootstrap，seed20260930，重算分子/分母，报告2.5/97.5百分位。另以目标物品为簇，同法seed20260931，作为依赖敏感性分析。两种区间均条件于固定图与数据，不是同时控制用户、物品及教师训练随机性的正式置信保证；随机重复/两模态不是独立实验seed。

## 6. 事前描述性决策

两模态分别报告，禁止事后挑k/目标组。硬验收通过后：

- `candidate_signal`：支持门槛均通过，Delta>=0.005（绝对0.5个百分点），且用户簇、物品簇两种区间下界均>0。
- `screen_stop`：支持足够且两种区间上界均<0.005；包括稳定低效用或反向结果。
- 其他均 `inconclusive`，保留数值与原因；不自动扩大预算。

0.005仅是本次资源决策的实用筛查门槛，约相当于全量6347目标正例多32次邻居历史命中；没有证据把它换算为推荐Recall增益，不是显著性/学位/创新标准。它是新候选筛查标准，不回写此前实验标准。两模态任一通过，只能支持评审该模态的知识共享对照，不立即证明值得训练复杂模块。若都停止，停止这份固定邻居配方；不声称所有多模态共享无效。

最强反对解释：教师Train协同信息已经编码了关联，且Validation复用；即便匹配频次后有Delta，也可能只是协同结构/历史长度交互效应，不能声称天然语义或稀疏问题已被修复。
