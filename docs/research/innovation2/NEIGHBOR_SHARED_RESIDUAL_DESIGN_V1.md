# 第二项方法设计 v1：模态邻域的共享残差学习

2026-09-29。状态：**候选算法设计，可评审，未实现、未训练、不是运行声明。** 用户转述另一AI同意进入方案评审；尚未收到该AI完整审计材料，因此不把转述写成已独立核验所有产物。本页不改变论文总体路线，不保证独立创新强度。

## 1. 研究问题与主张范围

冻结教师模态邻域中的关系，能否通过跨物品共享的排序更新，改善稀疏物品推荐，且在导出后仍使用64维ID表？

[已完成诊断](MODAL_NEIGHBOR_DIAGNOSTIC_RESULTS.md)支持“超出邻居频次的关联”，图像/文本差值+6.45/+11.28个百分点。未证明候选区分能力、对现有学生的信息增量、纯模态语义或简化致损。因此不用“修复简化造成的损失”作为事实。第一项是逐物品方向对齐；这里研究关系诱导的共享学习路径，而不是再加一个逐点KD项。

本轮只推荐一个主候选：**固定关系特征 + 共享线性残差 + BPR**。先不添加注意力、伪正例、梯度门控、元学习和多层图传播。复杂度必须由对照结果支持，不以模块或公式数量认定创新。

## 2. 具体结构与公式

### 2.1 固定资产与邻域

使用当前共同冻结缓存的`users/items`作为学生初始表和固定锚点，分别记p_u^0、q_i^0；`image_items/text_items`只用于邻域。沿用既有两模态k20真实邻居、相同零向量排除和低频三分组，不因文本诊断较强而改图文权重。仅对既有有效低组6114物品设置h_i=1，其余h_i=0。该分组依赖Train，频次5的ID边界限制保留，不声称冷启动。

每模态使用均匀权重，不追加相似度温度：

\[
 c_{i,m}=\frac1{20}\sum_{j\in N_m(i)}q_j^0,\qquad v_{i,m}=c_{i,m}-q_i^0.
\]

共享的是**冻结教师融合坐标中的邻域差分**，不是把原始图文直接相加，也不是复制邻居的正反馈标签。q_j^0始终冻结，阻断学生实时邻居相互追随；保留每物品可训练q_i，避免直接用邻居平均替代身份。

为控制特征量纲，用有效低组的Train派生集合计算

\[
 a_m=\sqrt{|S|^{-1}\sum_{i\in S}\|v_{i,m}\|^2},\quad
 x_i=\frac{h_i}{\sqrt2}[v_{i,image}/\max(a_{image},10^{-12});v_{i,text}/\max(a_{text},10^{-12})]\in\mathbb R^{128}.
\]

a_m无需Validation。若某模态a_m<1e-12，准备验收停止，不能以数值epsilon掩盖无信息分支。初稿不按d_i连续调强度，不额外引入待调参数。

### 2.2 共享映射与排序监督

\[
 \widetilde q_i=q_i+W x_i,\quad W\in\mathbb R^{64\times128},\qquad s(u,i)=p_u^\top\widetilde q_i.
\]

初始化p=p^0、q=q^0、W=0。因此epoch0全部用户物品分数与教师初始化+BPR基线**数学上相等**；实现应数值回归，不仅比较平均Recall。只有W新增8192个可训练参数，图和x固定。

\[
 L=\mathbb E_{(u,i,j)\sim\mathcal T}[-\log\sigma(s(u,i)-s(u,j))].
\]

本轮不加固定Full的方向KD、不加教师排序KL或伪正例。训练三元组、优化器预算保持与B相同；对正例i和采样未观测j都用完整新评分，不能只把残差作用于正物品。未观测j是协议负采样，不是真实负偏好。

令b=σ(-(s(u,i)-s(u,j)))，单三元组有

\[
 \nabla_W L=-b\,p_u(x_i-x_j)^\top.
\]

因此同一关系特征在帮助正例和抬高竞争候选时会收到相反训练信号；更新W同时影响其他具有相关x的物品。这是预期共享机制，**不是已证明避免负迁移的机制**。某些无本地正例更新的目标也可能被W改变，必须评估副作用。

### 2.3 为什么它仍可能有用，以及其数学退化

令X各行是x_i^T，Q_eff=Q+XW^T。固定X、无正则、Q和W同学习率的普通同时SGD下，若G=∂L/∂Q_eff，则

\[
 Q_{eff}^{new}=Q_{eff}-\eta(I+XX^\top)G.
\]

推导：ΔQ=-ηG、ΔW=-ηG^TX，代入即可。XX^T产生共享更新，秩至多128。它说明训练路径发生变化，**不说明一定改善泛化**。这不是新定理；实际采用AdamW时不能直接用该式描述真实更新，也不能把其PSD性质说成推荐收益保证。

特别重要：Q本来就是自由ID表，所以残差**没有扩大导出表示的函数类**。收益若存在，很可能来自重参数化、共享优化偏置或正则差异。不能把这些替代解释藏起来；同结构随机/自身特征对照是必须的。若该候选只呈现一般重参数化收益，应缩回工程/优化配方，不能宣称模态关系创新成立。

### 2.4 导出与成本

训练后一次性计算Q_export=Q+XW^T，导出P/Q_export，线上仍为64维内积，无邻居检索和新模块。数学上评分等价；浮点误差/TopK边界翻转须验收，不保证逐位相等。

X全表FP32约9.40MB，W约32KB（不含梯度/优化器）；也可只缓存有效低组约3.13MB。每批只对涉及的唯一物品算W x，避免每步导出全表。图准备/一次特征构建、训练、验证导出、服务成本分别计，不声称比同维缓存基线在线更快。更新W需刷新相关导出表，不能忽略更新成本。

## 3. 最小对照：先筛候选，再确认解释

所有训练臂共同p^0/q^0、全零AdamW状态、seed2022既有完整三元组tape、epoch300主终点。禁止从旧B final继续训练主候选却与旧300轮B直接比较。

| 臂 | 唯一差异 | 要排除的解释 |
|---|---|---|
| B | 教师初始化纯ID BPR | 主增量基线 |
| N | 上述真实图共享矩阵W | 主候选 |
| F | 同x，仅W=[b_image I,b_text I]，两个标量从0学习 | 是否只需简单全局平滑/模态权重 |
| R | 与N相同，改用已保存精确频次随机邻居的rep0 | 是否只是额外参数、优化路径或随机约束 |

首轮最多四臂，不先三seed/两数据集铺开。R的rep0在看训练结果前固定，不从100组选择；它只代表一个固定随机图，正结果后仍需检查随机图依赖。N/R各自按相同公式计算a_m，控制平均输入能量；但不等价于匹配每步梯度或AdamW更新量，须记录残差/更新范数。

F使用同等训练步数与BPR反馈，而不是随意设弱的固定平滑系数。W/标量的初稿学习率均6e-5、AdamW weight_decay .01、其余设置同历史B；参数化不同仍会改变有效更新尺度，不能据一次F失败宣布所有平滑无效。

仅当N显示增量且不被F/R解释，才另行评审以下两个必要对照（不是执行队列）：

- **C：协同邻居，同一W机制。** 邻域由Train二值列cosine共现构建，k20、自身排除、相同候选/查询。不足正相似度邻居时以0相似度、ID升序补足并报告比例。为了保留128维结构，两个64维块复制同一协同差分并按同一公式归一；说明两块重复、有效特征秩更低，因此也需报告谱/秩，不能称完全容量等价。若C效果相当，关系共享可能成立，但模态来源优势未成立。
- **S：自身特征，同一W机制。** 用q_i^0替代邻域差分，两个块复制归一化q_i^0；其他不变。检验一般共享重参数化是否足够。若S与N相当，不能把收益归因邻居关系。

固定后处理平滑评分也可从同一个B检查点形成成本参照，但首轮F已经是更直接的可学习简单替代；不另外堆后处理超参数搜索。第一项Full和PromptMM历史结果只作背景，不能代替新协议中的同起点B。

## 4. 从关联到排序：评价与停止规则

不再单独重复“邻居比随机有关联”的诊断。首轮直接让BPR面对正/采样负候选，并做原有全候选Validation排名；这检验关联是否真的可转化为排序收益。它仍不证明泛化到独立数据。

首轮计划锚定：Sports seed2022，300轮×214步，batch1024，AdamW6e-5、weight_decay.01、betas(.9,.999)、eps1e-8；精确参数/评价实现需在准备报告绑定原manifest，不靠本文重抄替代运行配置。最多四个训练臂，无Test。B回归epoch0=.094184495190847733，epoch300=.095151699965148426，容差1e-6；不通过则停止后续臂。

主终点固定epoch300，不按各臂最优轮选择。报告：总体Recall@20、原三分组低/中/高micro命中率与原Recall贡献、低组绝对命中数及曝光、固定epoch0/50/100/200/300曲线点、训练/导出成本。历史NDCG实现有已知问题，本首轮不沿用其值作判定；若未来要标准NDCG，须另固定修正协议，不能混算历史数值。

**建议的预注册筛查（设计值，正式准备冻结后才可执行）：** N−B低组micro>=.001（0.1个百分点，原6347正例约多7次命中），总体Recall差>=−.0002；且N低组micro分别高于F、R至少.0005。所有数值是低成本首筛标准，不是显著性或正式非劣。总体下降在容忍带内仍必须称有质量权衡，不能叫无损。主要看seed2022是否值得继续，而非认证稳健效果。

N若不能改善低组、总体损失越界，或F/R达到相当效果，则该配方`screen_stop`，保留结果，不自动调参补救。通过也只允许评审后续C/S及重复种子；不自动执行。不能用这一轮来确认“语义纯贡献”。若最终稳定收益只出现在已反复查看的Sports Validation，论文证据仍不完整。

最有希望的结果是低组得到小幅真实排名改善、总体基本保持且真实关系优于F/R；**目前没有依据预测具体Recall提升或成功概率**。本轮0.001阈值不是效果承诺。

## 5. 近邻工作与创新风险

本次为定向初查，不是穷尽检索，也没有完整逐式复现所有论文。

| 原始来源 | 已有内容 / 对本方案的约束 |
|---|---|
| [LATTICE](https://arxiv.org/abs/2104.09036) | 从模态内容挖掘物品关系并用于表示学习；“模态近邻共享”本身不新 |
| [FREEDOM](https://arxiv.org/abs/2211.06924) | 冻结item-item图并处理user-item图；“冻结图省成本”不能单独当创新 |
| [HTD](https://arxiv.org/abs/2106.08700) | 教师空间关系/拓扑蒸馏已有先例；“点对齐变关系传递”不是新颖性证明 |
| [PromptMM](https://arxiv.org/html/2402.17188v1) | 多模态教师向轻量学生迁移的直接近邻；不能宣称首次轻量多模态KD |

本候选与这些方法的待验证差别是：固定教师关系构造特征，通过共享残差直接由排序反馈学习，不强制复制教师拓扑，零残差起点保持强基线并可精确折叠到ID评分。这只是具体实现差异；共享线性层/残差/折叠都不是单独的新技术。

**创新风险为中高。** 若只需均匀聚合加线性W就产生收益，可能足以形成有价值改进配方，但算法独立性尚不扎实。只有证明针对稀疏性的共享更新带来超出一般重参数化、平滑和协同图的稳定收益，才有依据提炼独立贡献。暂不编造“自适应置信”“去噪选择”等未实现机制来增大创新叙述。完整近邻公式核查和最新相关方法覆盖仍需后续方案评审，本文不作首次/领先声明。
