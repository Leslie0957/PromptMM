# Sports 共享初值与目标方向证据综合（2026-09-24）

本页只综合已审计的 Sports Validation 和训练集零更新证据；没有新训练、选模、Test 排名或参数改动。`TRAINING_LOG.md` 仍是实验正本。四个暖启动臂使用同一保存的六张张量、同一教师与数据、seed 2022、300 轮/耐心 300、student LR 6e-5、batch 1024；初始用户/物品哈希及初始 Validation 一致。等权臂的八批次**定标**固定，正式训练没有保存逐批采样 ID，因此不能宣称训练三元组逐批位级相同。

## 观察到的结果

|暖启动臂|蒸馏目标及系数|最佳轮次（从 1 计）|最佳 Val Recall@20|同轮 NDCG@20|
|---|---|---:|---:|---:|
|BPR|无蒸馏，alpha 0|286|0.095477873096|0.043805670602|
|Full|`(Dimage+0.3 Dtext)/1.3`，alpha 0.3|283|0.095438076853|0.043780603134|
|等权匹配尺度|`(Dimage+Dtext)/2`，alpha 0.4111064309069839|299|0.095383454558|0.043722460516|
|Full 强度探针|`(Dimage+0.3 Dtext)/1.3`，alpha 3.0|3|0.094367089719|0.043365329516|

共同未训练起点 Recall@20 为 `0.094184495191`。BPR、Full 和等权臂最佳值差很小，排序为 BPR > Full > 等权；不能据此宣称统计上有优劣。alpha 3.0 的最优轮次为 3，最终 Recall@20 为 `0.092054380611`，低于共同起点；这是有效负结果。等权臂的最优轮次 299 靠近预算终点，不足以授权延长训练。四臂均是 Validation-only、`paper_ready_eligible=false`，无教师/学生 Test 排名；既有预检保留 Test 矩阵结构性读取。[Full/BPR 审计](SPORTS_SHAREDINIT_PAIR_AUDIT_2026-09-23.md)、[alpha3 审计](SPORTS_ALPHA3_AUDIT_2026-09-24.md)、[等权臂审计](SPORTS_EQUAL_MATCHED_AUDIT_2026-09-24.md)记录了各自完整指纹和结果。

## 机制证据的边界

1. **暖启动已给学生强表征。**初始 Validation Recall@20 `0.094184495191` 接近三个低强度臂训练后最佳值，BPR 单独微调略高于 Full。故本配置不能把暖启动后的高分归因于蒸馏。[共享初值配对](SPORTS_SHAREDINIT_PAIR_AUDIT_2026-09-23.md)隔离了初始向量来源。
2. **当前 alpha 0.3 的初始原始蒸馏梯度很小。**八个固定训练批次上，它相对 BPR 的均值范数为全参数 `0.456150%`、物品参数 `1.045023%`，物品梯度与 BPR 余弦 `0.010416`。图文梯度部分相反，但这不证明文本有害；损失数值相近也不等于梯度相近。这些只是初始原始梯度，不能当作 AdamW 步长占比或 300 轮机制。[初始梯度审计](SPORTS_GRADIENT_AUDIT_2026-09-23.md)。
3. **实际目标与教师最终初值方向不同。**按训练正物品的精确边际采样频率，`cos(F,1:0.3目标)` 均值 `0.4839051465`，等权图文方向为 `0.6917894593`；下降梯度在归一化 `F` 的切平面指向相应目标。`F` 还含 ID、提示和图传播成分，因此等权目标也不是 `F`。更接近 `F` 的方向本身不保证更好推荐质量。[采样加权方向审计](SPORTS_WEIGHTED_DIRECTION_AUDIT_2026-09-24.md)。
4. **改方向与改强度已在初始状态局部拆开。**同八批、同初值下，等权目标以 alpha `0.4111064309069839` 匹配 Full 的总物品梯度 RMS（双方 `4.7974599392e-5`），但梯度余弦仍为 `0.8654902201`（约 30.06°）。所以局部方向变化不是总强度变化的别名。然而一个全局系数未逐物品、逐更新匹配，且在同八批定标并审计；后续正式训练的等权臂没有验证优势。[匹配方向审计](SPORTS_MATCHED_TARGET_DIRECTION_AUDIT_2026-09-24.md)。
5. **简单放大并未解决暖启动问题。**alpha 从 0.3 提至 3.0 后语义损失下降更多而 Validation 变差，反驳“初始梯度小，所以放大就会增益”的直接推断。它不能独立定位是目标冲突、优化路径、过拟合还是其他因素。[alpha3 审计](SPORTS_ALPHA3_AUDIT_2026-09-24.md)。

这些结果共同支持一个受限判断：**在 Sports 的教师暖启动、当前目标和单一 seed 下，额外定向蒸馏没有显示超越 BPR 微调的验证收益。**它们没有证明蒸馏普遍无效，也没有证明 1:0.3、1:1 或任何 alpha 最优。

## 与随机初值证据的关系

随机 ID 初值的 Sports 三种子、300 轮 Validation 汇总：Full Recall@20 `0.08230706 ± 0.00024695`、图像权重匹配去文本 `0.07812907 ± 0.00068555`、BPR `0.04515130 ± 0.00043770`；逐 seed 的 Full 优势见[三种子报告](SPORTS_THREE_SEED_VALIDATION300_2026-09-18.md)。它表明蒸馏在**另一初始化制度**下有强验证关联。暖启动与随机初值的起点、优化轨迹不同，不能将两组指标直接相减来估计蒸馏的因果贡献，也不能用暖启动负结果否定随机初值效果。冷启动的 Full/图像/BPR 对比仍需机制归因，特别是文本方向的独立作用；第二创新点仍未确定。

## 决策

当前不再从暖启动单 seed 的微小差值继续扫 alpha、图文比例或追加轮数。唯一建议的下一阶段是**对现有随机初值三种子 Full、图像匹配和 BPR 的已保存 checkpoint 做只读表征归因**：仅用训练正物品采样权重与已有语义张量，比较各臂选中物品 ID 向量相对图像、文本和教师最终向量的方向变化，并保持同 seed 配对；不做参数更新、重选 checkpoint 或 Test 排名。先确认这些 checkpoint 和目标资产完整，再另行声明诊断协议。本页既未准备该诊断，也未授权新训练或 Test 访问。
