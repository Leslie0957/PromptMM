# Sports 轻量部署效率对照协议

| 臂 | 固定来源 | 用途 |

| S-Full | `sports_student_full_sharedteacherinit_seed2022_val300_v1` 所选推理 ID 表 | 暖启动蒸馏学生 |
| S-BPR | `sports_student_bpr_sharedteacherinit_seed2022_val300_v1` 所选推理 ID 表 | 同结构无蒸馏对照 |

学生源由[共享初值审计](SPORTS_SHAREDINIT_PAIR_AUDIT_2026-09-23.md)固定：Full 完整 checkpoint SHA256 `bd651d78ab8853ba987c407a23cd485581ccf319a1b6c9202c5413091fc6879c`，BPR 为 `2c35884bb4d1552fb346689732e3dcda9cbb6f59d50e8113495d62ae1e396e18`。实施时通过对应 manifest 定位已导出的推理表，核对与完整 checkpoint 两张表逐位相等，不加载优化器到 GPU。

教师参考资产为 `exp/initialization_checks/sports_initialization_repeatability_seed2022_v1/process0/initial_tensors.pt`，SHA256 `e5573bbdbbb609b4bc037a551455578463795c6df4bc4a1b236788d86c24da20`，只取 `users/items`。教师源 checkpoint SHA256 `57673a54603e2680416925d0c11b24d045b0ef14870feee292011032ea33abea`。数据沿用 SPORTS_CONVERTED_20260916，train_mat SHA256 `5361c5486dddbf50084d011278a11d2f18a37e258f87be218b070ff02f4ab0f8`。

三臂必须具有相同 user/item 数、64 维、float32、连续存储和设备；不量化、不剪枝、不降低候选数。若形状不符则停止，不能为获得速度差临时降维。这里只选一个已存在的训练 seed，因为目标是同形状部署工作负载；计时重复不是新的训练种子或质量复现。

## 2. 共同在线路径

主测 GPU0，环境为 `D:/miniconda/envs/run_5060/python.exe`，记录实际 GPU、驱动、PyTorch/CUDA、CPU、线程数和精度开关。统一关闭 TF32、autocast、编译及异步跨批流水；不从历史训练速度推导效率。

单独实现无训练入口副作用的评分函数，三臂共用：

1. 从常驻 GPU 的 user 表取固定用户批次；item 表常驻 GPU。
2. `scores = user_batch @ item_table.T`，对全部物品打分。
3. 用同一预加载训练交互 mask 排除已见物品，GPU `topk(k=20)`。
4. 将这批 top20 分数及物品 ID 复制到 CPU；计时结束前同步完成。

这是无标签的服务负载，不计算 Recall/NDCG，也不访问 Validation/Test 用户列表或正例。只读取 train_mat 构建请求和排除项；不输出原始推荐列表，最多保存结果摘要以验证实际执行。

固定请求：对有训练交互且至少20个未见物品的用户按 ID 排序，使用独立 NumPy RNG seed `9026026` 置乱；不足则停止。批大小 `1/128/1024`，按置乱序列循环切片，三臂逐请求完全相同。请求张量、mask 索引预加载成本归启动阶段；在线计时包含 gather、矩阵乘法、mask、topk 和 CPU 返回。另报告仅矩阵乘法的 CUDA 事件计时，但不将其冒充服务总延迟。

现有 `codes/utility/batch_test.py` 在导入时构建 Data，并包含 CPU 拷贝、多进程和标签指标；新基准不得直接导入它或 `main_mmlight.py`，防止结构性 Test 读取及不同评估开销混入。上述 GPU topk 路径是三臂共同的部署基准，不声称与旧 Python heapq 评估器耗时相同。

## 3. 离线成本和内存的边界

分别报告以下成本，不将不同阶段累加成未定义的“加速倍数”：

| 阶段 | 教师 | 学生 | 口径 |
|---|---|---|---|
| 在线缓存服务 | 仅两张最终表 | 仅两张 ID 表 | 相同评分实现；在线教师不保留图、模态或教师模型 |
| 固定权重表征生成 | eval/inference_mode 下完整教师+prompt 前向，输出最终表 | 从已加载学生表导出/复制最终表 | GPU输入预先常驻；同步计时；不含读取/构图/序列化 |
| 启动与导出 | 源文件读取、图/模态准备、设备传输、最终表写盘 | 源文件读取、设备传输、最终表写盘 | 各阶段分别墙钟计时，不与常驻前向混合 |
| 部署资产 | 最终两张表及共同元数据 | 最终两张表及共同元数据 | 同格式；报告逻辑tensor bytes及实际文件bytes |

教师新前向的实现需要独立 train-only 构造器，从原 manifest 恢复全部模型/prompt/图归一化参数；不得重新生成或覆盖硬 token 缓存，不得复制半套逻辑后宣称等价。准备阶段用源码映射及合成测试核对；首次真实前向只在之后用户授权的基准中执行，并验证输出有限、shape/dtype 一致、与固定参考表在 `atol=1e-4, rtol=1e-4` 内一致，记录最大绝对/相对误差。若不满足则停止并保留报告，不放宽容差重试。T-cache 在线仍固定使用上节参考资产，不依运行结果换表。

完整教师常驻参数、模态、图与 prompt 资产另列资源清单；按底层 storage 去重，不能只数 trainable 参数或只读 state_dict 文件大小。在线独立进程只保留评分所需表与公共 mask/请求，避免教师离线缓存污染在线显存。报告 GPU baseline/peak allocated、baseline/peak reserved、增量峰值及进程工作集；说明后者包含解释器/库开销。

同形状同 dtype 时，两张最终表的逻辑字节数必然相同：`4*64*(n_users+n_items)`。因此不预期通过本对照证明缓存表压缩。教师完整模型与学生表的体积差只能标记为完整资产对比。

学生静态导出不等于吸收新交互后的更新。教师/学生再训练、新用户物品适配、原始图文编码器生成特征均在本协议之外；不得把静态前向差宣传为训练或全生命周期节省。磁盘读数受 OS 缓存影响，不称“冷盘读取”，不强制清系统缓存。

## 4. 次数、顺序及运行条件

- 一个用户手动启动的串行批次；不得并发 GPU 工作。3个计时轮，每个条件独立子进程，臂顺序依轮为 T/F/B、F/B/T、B/T/F；批大小顺序依轮为 1/128/1024、128/1024/1、1024/1/128。
- 每个在线条件20次预热、100次计时，完整原始耗时保留。CPU返回墙钟时延使用同步边界；吞吐按总用户数/总墙钟时间计算。逐轮报告 median、p95和吞吐；跨轮报告轮级中位数及范围，不把300次相关测量当独立样本做显著性结论。
- 固定权重表征生成每臂每轮3次预热、10次计时；生成输出不反复写盘。启动读取/最终序列化各轮各测一次，独立记录。实施时给计时循环和 worker 设置明确上限，异常或超时不自动重跑。
- 用户保持供电、相同电源/性能模式，终端前台可见，无其他全屏应用或同时训练；启动前手动关闭额外 GPU 负载。记录运行起止时间、GPU温度/频率/功率/利用率（可取得时）及用户确认的窗口条件，不自动修改系统或驱动设置。
- 若用户切换全屏状态、系统休眠、外部负载干扰，标记对应测量受干扰，保留所有读数；不删除慢值或只挑最快一轮。遥测不可用时明确记缺失，不声称已证明无节流。

## 5. 有效性、输出与解释规则

实施前先在合成小表上核对共享 scorer：matmul、训练mask、topk正确性及同输入一致性；固定记录平分边界处理，不能要求不同模型给出相同推荐。真实测量核验源资产、有限输出、未修改输入权重、三个臂请求完全一致。无标签排名合法执行但 Validation/Test指标调用次数必须为0；不调用优化器。

独占忽略输出建议为 `exp/efficiency/sports_cached_deployment_seed2022_v1/`：manifest、请求顺序/来源hash、环境、原始计时、轮级汇总、内存和文件体积、正确性及零更新证据。已存在目录即停止；不覆盖基线表或历史checkpoint。精确实现源码、resolved参数、launch HEAD、clean状态、超时和完整命令将在**实现准备完成后**另写正式手动运行声明。

解释先遵循同工作量和测量有效性，不设“必须加速”的验收条件：

- 若缓存在线速度及逻辑体积相近，如实报告；Full/BPR同结构的细小差异不能当作蒸馏贡献。
- 若仅离线生成更便宜，只声称冻结权重下表征生成成本降低；不声称在线查询或训练同比加速。
- 若计时不稳定或数据受干扰，仅保留描述性读数，不宣布可靠速度比。
- 既有质量结果仅引用已有 Validation审计，不重评、不改变选中checkpoint；不能据此宣称与教师质量无损等价。
