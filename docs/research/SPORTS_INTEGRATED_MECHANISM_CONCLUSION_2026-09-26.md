# Sports 机制结论：真实残差、图像对照与教师暖启动

本页整合截至 2026-09-26 的已审计证据。仅核对已有文档、报告与源码；没有新训练、模型前向、梯度、选模或 Validation/Test 排名。实验正本为 `TRAINING_LOG.md`。本文定稿的是**当前证据所支持的表述**，不作论文结果冻结、标签或正式 Test 声明。

## 1. 最终可支持的核心表述

> 在 Sports、固定教师和 300 轮训练预算下，从随机 ID 表征出发时，加入当前文本方向蒸馏项，相比保持图像项系数相同的图像对照，三个种子的 Validation 指标一致提高。进一步固定初值、全部训练三元组及共同教师语义，并保持逐物品目标几何和近乎相同的初始蒸馏梯度尺度后，真实文本残差仍一致优于预先固定的随机残差对照。这支持真实文本残差结构能为该冷初值训练提供有用信息。教师表征暖启动的单种子实验则未显示当前蒸馏项超出 BPR 微调的额外验证收益。

这里的“冷初值”指**已有用户/物品的随机 ID 参数初始化**，不是新用户或新物品冷启动推荐。暖启动和冷初值之间尚未形成只改变初始化的完整因子实验，不能量化或宣称已识别“初始化与蒸馏的因果交互”。

## 2. 三组证据分别回答了什么

| 冷初值真实 / sham，3 seeds | 均值 0.082307064899 / 0.076872319199；差 +0.005434745700（相对 +7.0698%） | 在此次目标几何及初始尺度匹配条件下，正确残差方向优于所测随机残差 |

Full/image 的实际图像系数都是 `0.3/1.3`；Full 额外有文本系数 `0.09/1.3`。这组实验匹配的是**图像项系数**，没有匹配总蒸馏梯度大小，因此单独不能区分文本方向与新增约束强度。该组各进程教师中间语义没有逐位存档核对。

真实/sham 使用相同的六张教师张量资产，并回放各 seed 保存的初值与完整 64,200 批训练三元组。初始八批的 sham/real 物品蒸馏梯度 RMS 比为 `1.000192460 / 0.999797437 / 1.000075226`。三个 Recall 差为 `+0.004859757715 / +0.005124176237 / +0.006320303149`，满足预先声明的“三对为正且均值 ≥0.00209”支持标准。这增强了方向信息作用的证据，削弱了“此次收益仅来自任意几何相似第二方向约束”的解释。

sham 同时破坏了真实残差的跨物品结构，因而还不能分离自然语言语义、物品对应关系与跨物品几何各自的贡献，也不能宣称所有随机或非语义约束都无效。每个训练 seed 只对应一个预设 sham seed；三个 sham 最佳值均在第 300 轮。结论针对此预算，不是充分收敛后的比较，也不是显著性检验。

两批真实 Full 的所选指标相同，不代表权重或整个训练轨迹逐位相同。旧 image 与新 sham 的数值顺序可作背景，不能从两组差值相减得到新的严格配对因果效应。

## 3. F、1:0.3 目标与实际梯度的统一解释

令 `v,t` 为单位化教师图像/文本向量，当前组合目标 `q=(v+0.3t)/1.3`，教师最终物品向量为 `F`。归一化 MSE 源码及[采样加权诊断](SPORTS_WEIGHTED_DIRECTION_AUDIT_2026-09-24.md)给出：对非零学生物品向量 `s`，单正样本、批均值前的梯度是

\[
\nabla_s L_{KD}=-\frac{2\alpha}{d\|s\|}(I-\hat{s}\hat{s}^{\top})q,
\qquad d=64,\quad\alpha=0.3.
\]

实际批次再按物品出现次数及批大小聚合。按采样器的精确正物品边际概率 `p_i=|U_+|^{-1}\sum_{u:i\in I_u^+}|I_u^+|^{-1}` 加权，`cos(F,N(q))=0.4839051465`，而等权方向为 `0.6917894593`。`F` 还包含 ID、提示和图传播成分，当前蒸馏确实施加了不同于直接保持 `F` 的切向约束。

这解释了为什么“目标更接近 F”“蒸馏损失更低”和“推荐指标更高”不能互相替代：优化的方向约束与推荐排序目标并非同一个量。等权初始尺度匹配后没有提升，以及 alpha3 语义损失下降更多却验证变差，均不支持把前两者当作质量保证。但这些结果没有证明方向偏离 F 就是 alpha3 退化的唯一原因。

暖启动八批的物品蒸馏/BPR 梯度范数比**均值**为 `1.045023%`；冷初值八批的物品梯度 **RMS 之比**约 `2.331078 / 2.355102 / 2.337557`。两者初始化和统计量不同，不能相除后宣称机制强了多少倍，更不能当作 AdamW 更新贡献。共同可说的是：已有局部诊断呈现不同的梯度状态；它们尚未记录整个训练轨迹。

## 4. 暖启动高分与轻量部署如何归因

暖启动未训练学生的 Recall 已为 `0.094184495191`，随后 BPR 单独微调达到 `0.095477873096`。这直接支持教师表征作为强起点的价值，当前暖启动高分不能全归因于后续蒸馏。“起点已有有用结构，额外约束可能冗余或造成优化取舍”是与结果相容的假说，尚未被唯一确认。冷初值收益不能外推成暖启动收益，暖启动近似持平也不能否定冷初值收益。

轻量部署仍有独立价值。源码 `codes/td_distill_model_no_projection.py` 的 `forward()` 与 `export_infer_state_dict()` 表明，学生推理资产仅需用户/物品 ID 表及元数据；暖启动后这种结构仍然成立。BPR、Full、真实/sham 对照拥有相同学生部署结构，因此轻量性属于学生架构与表征转移路径，不能单独归因于文本蒸馏损失。

当前这几组实验未测得可归因的加速倍数、显存/内存节省或端到端成本收益。公平效率结论还须考虑教师同样可以缓存最终用户/物品表示，分别核算离线生成/刷新成本与在线查表排名成本；不能用每次在线重算教师图传播的设置夸大学生优势。先前受全屏和系统负载影响的训练 it/s 不构成效率证据。

## 5. 可写与不可写的边界

**可直接写：** 当前方向蒸馏在 Sports 冷初值训练中体现了文本残差方向相关的固定预算验证收益；几何及初始梯度尺度匹配的随机残差对照为这一点提供了进一步支持。教师暖启动下暂未观察到超出 BPR 的增量收益，学生 ID-only 部署结构仍成立。

**暂不可写：** 已证明唯一语义因果机制、所有初始化都有效、文本必不可少、1:0.3 或 alpha0.3 全局最优、已完全解释暖启动退化、全程梯度/更新等强、统计显著、充分收敛、Baby 或 Test 泛化提升，或已测出效率优势。也不能据此确定第二创新点。

本页引用的训练均为 Validation-only，保留原加载器结构性 Test 读取；教师/学生 Test 排名为零，`paper_ready_eligible=false`。本次综合没有读取 Validation/Test 分割矩阵。Baby2023 原 manifest=false 的已接受审计例外、Innovation2 未定状态不变。忽略产物仍未获得此文档提交之外的物理备份保证。

## 6. 唯一后续建议

单独授权后，准备**公平的 ID-only 部署效率对照协议**，包括教师最终表征缓存基线、相同打分/候选实现及离线与在线成本分开核算，用以检验轻量结构能带来多大的实际收益。本次仅提出该方向，不编写运行命令、不准备或启动任何新实验。所有后续执行仍由用户完成。
