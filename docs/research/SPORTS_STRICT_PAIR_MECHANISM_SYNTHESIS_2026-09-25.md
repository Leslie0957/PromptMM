# Sports 严格配对后的机制归纳与下一项验证设计（2026-09-25）

本页仅综合已审计的训练与零更新报告，未做新模型前向、梯度、优化、Validation/Test 排名或目标资产生成。正式实验记忆仍以 `TRAINING_LOG.md` 为准。本文选择**一项尚需单独授权**的后续验证，不构成运行声明或启动许可。

## 已经确定的关系

1. **冷初值下，文本项的验证关联经严格配对仍存在。** 三个 Sports seed 的 Full 和 image-matched 共用逐位相同的随机 ID 初值和每个 epoch/batch 的 64,200 组三元组，固定数据、教师、模型、优化器、图像项实际系数、300 轮及 Validation 选模。Full 的最佳 Recall@20 依次高 `0.003678244039`、`0.003665425535`、`0.005190323937`，平均高 `0.004177997837`（均值比 `+5.3476%`）；同轮 NDCG 三对也为正。[严格配对审计](SPORTS_PAIRED_COLDINIT_THREE_SEED_AUDIT_2026-09-25.md)记录所有原始指纹。当前加权平均损失下，Full 的图像系数为 `0.3/1.3`，image-matched 的图像系数也为 `0.3/1.3`；Full 额外有文本系数 `0.09/1.3`。因此新增文本项是最明确的**干预差别**，但该差别同时引入了正确文本方向和第二个方向约束，不能仅凭此结果区分两种作用。
2. **目标几何与教师最终向量不同。** 按训练正物品的真实采样边际概率加权，教师最终物品方向 `F` 与当前 1:0.3 图文目标 `q` 的平均余弦为 `0.483905`，与等权图文方向为 `0.691789`。`F` 还包含 ID、提示和图传播路径；目标越接近 `F` 并不自动带来更好排名。[加权方向诊断](SPORTS_WEIGHTED_DIRECTION_AUDIT_2026-09-24.md)用解析梯度和自动求导核对了该目标在归一化学生向量切平面上的梯度，证明是有实际作用的方向约束，而非目标定义上的同义替换。
3. **初始梯度证据属于暖启动局部。** 同一暖启动初值的八个训练批次，Full 蒸馏相对 BPR 的原始参数梯度范数均值为全参数 `0.456150%`、物品参数 `1.045023%`，物品梯度余弦 `0.010416`；图文梯度部分反向。等权图文目标把物品梯度 RMS 匹配到 `4.7974599392e-5` 后，与 1:0.3 目标仍只有 `0.865490` 的方向余弦。这排除了“初始两个方向仅总强度不同”的解释，却不说明冷初值时的梯度比例、AdamW 更新比例或后期轨迹。[梯度审计](SPORTS_GRADIENT_AUDIT_2026-09-23.md)、[匹配目标方向诊断](SPORTS_MATCHED_TARGET_DIRECTION_AUDIT_2026-09-24.md)。
4. **暖启动没有同样收益。** 共享教师初值 seed2022 的最佳 Validation Recall@20 为 BPR `0.095477873096`、Full `0.095438076853`、等权梯度尺度匹配臂 `0.095383454558`；alpha 从 `0.3` 放大到 `3.0` 后下降到 `0.094367089719`。这与起点已有较强推荐表征及对最终教师方向施加不同目标的局部梯度相容，但不能单独确认退化机制，也不能推翻冷初值的三种子优势。[前次机制综合](SPORTS_SHAREDINIT_MECHANISM_SYNTHESIS_2026-09-24.md)。
5. **所学表征发生了文本特异方向变化。** 旧冷初值三种子所选物品 ID 向量相对文本去图像残差的采样加权余弦，Full 平均 `0.298963`、image-matched 平均 `0.014695`；三对差约 `+0.284`。Full 的图像方向余弦略低，而教师最终方向余弦更高。[所选状态几何](SPORTS_COLDINIT_SELECTED_GEOMETRY_2026-09-24.md)只是描述性证据：它用的是旧 checkpoint 和后续保存的共同教师参照，不是新严格配对六臂的训练前后位移，也不是排名收益的中介证明。新六臂最佳指标/轮次与旧臂相同，但权重不逐位相同，不能把两批资产混作同一次轨迹。

**当前最窄的机制判断：** 在固定 Sports 数据、教师、训练预算、随机 ID 初值、逐批三元组和图像蒸馏系数后，加入当前 item-text 目标使三种子验证指标一致提高；训练出的物品方向也与文本独有残差更接近。冷初值更可能需要训练期的语义约束，教师暖启动则已给出较好的起点。现有证据没有区分“正确物品文本残差含有有用信息”和“任意额外、几何相似的方向约束提供了正则化”。也没有冷初值全程梯度/更新记录、跨教师种子结论、Test 结论或 Baby 论文主实验结论。

## 唯一建议的后续验证：文本残差几何匹配的伪目标对照

**可证伪问题：** 当前 Full 的增益是否依赖每个物品**正确的文本独有方向**？推荐一组 Sports 三 seed 的严格配对 Validation-only 实验，每个 seed 重新比较真实 Full 与伪文本残差臂，沿用现有保存的该 seed 初始 ID 表和全部训练三元组；两臂共享**同一份冻结教师语义张量资产**，防止跨进程重算教师目标成为新混杂。需要单独授权实施、预声明及手动启动；本文没有新 profile、命令或运行资产。

对每个有训练正样本且非零目标的物品，设单位化图像方向 `v_i`、真实文本方向 `t_i`、`c_i=v_i·t_i`、真实残差方向 `r_i=normalize(t_i-c_iv_i)`。用预先固定的随机种子，为该物品生成与 `v_i` 正交的随机单位向量 `s_i`，构造伪文本方向

\[
t_i^{sham}=c_i v_i+\sqrt{1-c_i^2}\,s_i.
\]

这样逐物品保留 `||t_i||=1`、图文夹角 `c_i`、残差长度和合成 `v_i+0.3t_i` 的范数，仅破坏正确文本残差的方向与物品身份对应。零目标或退化残差物品采用预声明的固定处理规则，不能借助 Validation 选择随机向量。三个 seed 可使用各自预先固定的伪目标随机种子，避免一个偶然伪目标决定整个结论；这些种子在正式声明中写死。模型参数、BPR、训练批次、教师图像目标、用户项权重、Full 的 `alpha=0.3` 与 item image/text rates `1/0.3`、优化器、300 轮和选模规则相同。两臂只有 item-text 目标中残差方向不同。

**启动前硬门槛：** 核验三组已保存初值/批次 SHA；把原始教师图文目标冻结为一个可复用、带 SHA 的资产；在各 seed 固定的前八个训练批次做零更新检查，逐物品图文夹角与合成目标范数须在数值容差内相等，并报告真实/伪目标的加权物品梯度 RMS、图像梯度和 BPR 梯度。预设全局真实/伪蒸馏梯度 RMS 比在 `0.95–1.05` 之间作为尺度可比门槛；若不满足，应停止并修改声明，不能在看过 Validation 后调 alpha 或重新挑选伪目标。这个门槛只限制初始局部尺度，不能保证 AdamW 全程更新等强。运行仍由用户手动执行、每臂一次、第一失败即停，严格 Validation-only、零教师/学生 Test 排名。

**主要读数和解释：** 事前确定三对的最佳 Validation Recall@20 差（真实 Full−伪残差），同轮 NDCG@20 为辅助；同时将既有 image-matched 三种子指标作为背景锚，不把旧臂并入新配对统计。如果三对差一致为正且均值达到当前 Full−image 差的一半（`≥0.00209`），则支持正确物品文本残差超出一般方向正则化的作用；如果差接近零（绝对均值 `<0.001`）或伪目标更好，则“文本语义身份是必要条件”的解释被削弱；其余情形记为未定。无论结果如何，只能在 Sports 此教师和预算下解释，不自动宣布统计显著、充分收敛或论文正式 Test 增益。

这一项比继续调 alpha、训练更久或仅重复目标方向余弦更能直接区分当前两个机制解释。Baby 上的迁移与效率价值是之后独立阶段，不能由本 Sports 伪目标对照自动推出。
