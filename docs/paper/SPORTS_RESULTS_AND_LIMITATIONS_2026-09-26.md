# 论文结果与局限草稿：Sports 文本方向、暖启动及效率

用途：可整理进论文的中文结果段落。以下是已有审计结果的文字组织，没有新增实验或评估；“论文草稿”不改变任何运行的 `paper_ready_eligible` 状态。Sports 结果均须标为 **Validation**，不能填入正式 Test 表。

## 1. 文本方向监督的收益

在 Sports 数据集上，我们首先考察随机 ID 参数初始化条件下的文本方向监督。固定教师、300轮训练预算，并在每个随机种子内共享相同的用户/物品初值与全部训练三元组后，完整图文方向监督相对于匹配图像项实际系数的图像对照，在三个种子上的最佳 Validation Recall@20 均提高。两者均值分别为0.082307和0.078129，平均差为0.004178，相对提高5.35%；Recall选中轮次的NDCG@20也在三对比较中一致提高。这表明在当前配置和预算下，添加文本方向项能够改善随机初值学生的验证表现。[证据A](../research/SPORTS_PAIRED_COLDINIT_THREE_SEED_AUDIT_2026-09-25.md)

进一步地，我们采用真实文本残差与几何匹配随机残差的对照。两臂固定初值、训练批次和同一份教师语义张量，逐物品保留图文夹角、文本范数与组合目标范数；初始八批的随机/真实蒸馏梯度RMS比为0.999797至1.000192。真实目标在三个种子中均优于随机对照，平均Recall@20分别为0.082307和0.076872，平均差0.005435，相对提高7.07%，达到事前规定的支持标准。该结果支持真实文本残差结构为学生训练提供了超出此次几何匹配随机方向约束的有用信息。[证据B](../research/SPORTS_SHAM_RESIDUAL_AUDIT_2026-09-26.md)

上述“随机初值”是已有用户与物品的参数初始化方式，并非未见用户或物品的冷启动推荐任务。图像对照的目标仍来自多模态教师，不能等同于完全没有文本信息的系统。Full/image对照未逐位保存并核对各进程产生的教师中间语义；后续真实/sham对照使用同一份保存语义张量。两组对照各自配对，不能把历史图像臂与新随机残差臂拼成额外的严格三臂因果比较。

## 2. 教师暖启动下的增量收益边界

教师表征初始化后，未训练学生的Validation Recall@20已达到0.094184。在相同保存初值、seed2022和300轮预算下，BPR微调与完整蒸馏的最佳Recall@20分别为0.095478和0.095438，差值约为−0.000040。因此，当前暖启动实验没有显示额外方向蒸馏超过BPR微调的验证收益；这些微小差异不足以证明统计等价或BPR显著更优。暖启动后的较高指标不能全部归因于后续蒸馏。[证据C](../research/SPORTS_SHAREDINIT_PAIR_AUDIT_2026-09-23.md)

局部目标诊断与强度对照进一步说明，几何接近和更强目标拟合并不保证更好的推荐排序。按训练正物品采样概率加权，教师最终方向与当前1:0.3目标的平均余弦为0.483905，与等权图文方向的平均余弦为0.691789；然而初始物品梯度RMS匹配后的等权目标最佳Recall@20为0.095383，未改善当前Full结果。将Full蒸馏系数由0.3增至3.0后，最佳值为0.094367，最终值为0.092054，低于共同初值。这些结果不支持仅通过接近教师最终方向或放大蒸馏强度来保证增益，也未唯一确定退化原因。[方向诊断](../research/SPORTS_WEIGHTED_DIRECTION_AUDIT_2026-09-24.md)、[等权对照](../research/SPORTS_EQUAL_MATCHED_AUDIT_2026-09-24.md)、[强度对照](../research/SPORTS_ALPHA3_AUDIT_2026-09-24.md)

## 3. 阶段性效率结果

为区分学生结构简化与缓存带来的收益，我们比较缓存教师最终表、暖启动Full学生和BPR学生，统一64维FP32表示、全物品打分、训练已见项排除及Top20返回路径。三轮重复计时中，批大小1024时三者的轮级中位数之中位数分别为2.108950、2.112250和2.114050毫秒/批。其他批大小下也未呈现学生一致的速度优势。三臂向量表逻辑体积均为13,812,480字节，同批大小的在线GPU allocated内存读数相同。因此，本实验没有证明学生相对于同维度缓存教师的在线查询加速或缓存表压缩。[证据D](../research/SPORTS_CACHED_DEPLOYMENT_AUDIT_2026-09-26.md)

在固定权重、输入已就绪的离线表征生成阶段，完整教师前向与Full学生表复制的时间分别为15.889450和0.109900毫秒。该阶段约144.58倍的耗时比反映了学生生成冻结ID表征时省去教师图传播和模态计算的事实；它不包含读取、构造、传输与序列化，也不代表在线服务、训练或新数据适配的同等加速。BPR学生具有相同部署结构，因此该结构成本差异不能独立归因于文本蒸馏损失。

## 4. 局限性

本研究的上述机制证据限于Sports、单一固定教师和既定训练预算。三个随机残差臂的最佳验证值均位于第300轮，因而不代表充分收敛后的优劣；每个训练种子只使用一个预设随机残差实例，不能据此宣布统计显著性。随机残差干预同时改变物品对应方向与跨物品残差结构，尚不能分离自然语言语义、身份对应和跨物品几何各自的贡献。初始梯度尺度匹配也不等于全程梯度或AdamW更新等强。暖启动仅有单种子证据，且并非所有历史训练臂都保存了逐批采样身份；冷、暖两组之间尚不足以识别仅由初始化引起的因果交互。

当前证据不支持方法整体优于充分调优的PromptMM：共享Sports教师的发布版适配在学习率6e-5时，三种子Validation Recall@20均值为0.087573，高于随机初值Full的0.082307。该对照仍受初始化、结构和调参预算差异限制；不能隐藏这一结果，也不能外推为两种方法的普遍排序。[发布版对照](../research/PROMPTMM_LR6E5_THREE_SEED_2026-09-22.md)

效率测量为单机短时重复，保留全部慢样本，未证明运行全程不受环境扰动。离线内存统计包括原教师实现保留的部分未参与forward的参数，峰值窗口也包含计时外正确性检查，不能代表最小优化教师的资源下界。所有上述Sports质量证据均来自Validation，效率测试不使用质量标签；这些结果不构成新的Test泛化结论、质量无损压缩证明或第二创新点的完成证明。
