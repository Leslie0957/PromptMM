## 决策

**保留为“冻结多模态教师下，纯 ID 学生的简化方向监督及适用边界”研究；当前不认证其为充分独立的算法创新，不主张相对 PromptMM 的线上降本或完整质量—成本优势。** 已有结果可进入论文方法、实验与局限章节。研究问题成立、配方有效、方法新颖、满足学位要求是四个不同判断。

## 1. 研究对象与已有工作的关系

当前链路为“已训练多模态教师 → 当前 Full 学生”；发布版 PromptMM 学生是共享教师的另一对照分支。没有先训练原学生再将它蒸馏一次的依赖。教师检查点及图文分支缓存提供监督；暖启动复制的是教师最终表示。见 [main_mmlight.py](../../codes/main_mmlight.py) 的 `teacher_checkpoint_for_student`、`train_td_distill` 与 `td_init_from_teacher`，以及 [ID 学生实现](../../codes/td_distill_model_no_projection.py)。

| 维度 | 已有工作 / 继承部分 | 当前可核对的差异及限度 |
|---|---|---|
| 学生部署 | PromptMM 已用 LightGCN 学生最终用户/物品表示推荐，学生不编码图文；TARec 也已研究 ID 学生 | 当前只有两张可训练 ID 表，训练及表示生成均无学生图传播；“ID-only”本身不能称首次 |
| 知识传递 | PromptMM 已有教师模态物品嵌入蒸馏，并结合排序蒸馏 | 当前用正物品采样的图文分支方向监督，与 BPR 联合；去掉成对/列表 KD 不能自动证明更好 |
| 目标与参数 | PromptMM 论文含 SCE 及学生阶段 prompt 更新；发布实现存在差异 | 当前归一化 MSE、固定教师和 prompt、无投影，Full 图文权重 1:0.3；固定超参数不是新损失或最优性证据 |
| 监督范围 | 发布版适配采用全物品特征项和教师初始化 | 当前正物品采样导致频率加权监督，主表 Full 为随机初始化；多处差异同时存在，主表不是单因素归因 |

原始文献：[PromptMM §3.1–3.2](https://arxiv.org/html/2402.17188v1)、[TARec 作者机构摘要](https://eprints.gla.ac.uk/346364/)。后者用于确认 ID 学生已有先例，不作为逐式实现审计。PromptMM 论文与实际使用的发布版适配必须分开，详见[固定发布版身份核定](../research/PROMPTMM_BASELINE_IDENTITY_2026-09-18.md)。本次为定向近邻核查，不是穷尽文献的新颖性认证。

补充代数边界：对非零向量和 d 维均值归约，归一化 MSE 等于 `2/d × (1 − cosine)`。因此“方向蒸馏”与余弦嵌入对齐有直接联系，不能通过命名把已有损失变成新损失。完整配方的差异需要整体论证。

## 2. 实际得到什么、付出什么

| 问题 | 现有证据 | 允许的结论 |
|---|---|---|
| 比同结构 BPR 有用吗？ | Baby Test R@20：Full 0.066244 / BPR 0.041131；Sports：0.082908 / 0.044287 | 两数据集固定配置、各三学生种子均有收益；非充分调优优势 |
| 比 PromptMM 学生更好吗？ | 发布版共享教师适配 Baby 0.065039、Sports 0.089935 | Full 在 Baby 均值略高、Sports 更低；未全面胜出，未建立质量非劣保证 |
| 文本方向有作用吗？ | Sports Full/image 与 real/sham 严格配对 Validation 为正 | 支持所测随机初值、预算下方向结构的作用；未唯一分离自然语言语义，不能升级为 Test 因果结论 |
| 暖启动有增益吗？ | Sports 单 seed Full 未超过同初值 BPR | 增量收益存在边界；不证明所有暖启动都无效 |
| 线上是否降本？ | 同维缓存教师、暖启动 Full、BPR 在线无一致优势且表大小相同 | 已有基准不支持独有线上加速或缓存表压缩 |
| 离线是否降本？ | 冻结教师生成 15.889450 ms，Full 表复制 0.109900 ms | 只支持所测表示生成阶段的差异；未测训练总成本、动态更新成本或相对发布版学生的生成优势 |

**纠正此前聊天口径：效率基准没有 PromptMM 发布版学生这一臂。** “未测得相对缓存教师的一致在线优势”是实测事实；“同维 PromptMM 最终表也可缓存、用相同点积打分”是结构推论；“尚未证明相对 PromptMM 的效率优势”是证据状态。不得写成已实测两者等速。图传播能够离线完成，不能假定每个请求必须重算；教师本身已有缓存时，固定权重重复生成的阶段优势也未必带来实际运维收益。

## 3. 可采用的立项叙述

> 多模态推荐利用内容信息改善表示学习，也引入表征计算与维护开销。已有 PromptMM 等工作通过蒸馏训练轻量学生。本文进一步研究：固定多模态教师后，能否采用无图传播的纯 ID 学生，以正物品图文方向监督联合交互排序目标获得有效推荐？在 Baby 与 Sports 的固定配置中，该配方相对同结构 BPR 有收益；与 PromptMM 发布版适配的结果存在数据集差异。受控验证实验及阶段成本测量进一步刻画其文本方向作用、初始化依赖和缓存部署边界。

题目/章节名候选：**冻结多模态教师下的纯 ID 方向蒸馏及其适用边界**。引言应先承认已有蒸馏学生，再提出具体研究问题；不要把“现有多模态推荐线上普遍昂贵”当作已验证前提。

## 4. 继续与停止的判据

- **可以继续写**：方法变体、固定配置结果、方向机制及负结果边界。有研究价值不等于已证明充分的独立算法创新。
- **当前不能宣称**：新蒸馏范式、首次 ID 学生、新归一化损失、优于 PromptMM 的综合性价比、线上降本、无损压缩、训练/更新加速、统计显著或学位充分性。
- **若坚持效率为核心贡献**：须另定真实部署场景和完整成本口径，纳入原 PromptMM 学生、缓存及质量约束；当前缺直接证据，不能用旧阶段计时填补。本条是条件性缺口，不是运行计划或授权。
- **若按现有有限主张写作**：不因 Sports 低值追加调参或种子；先确认这种“简化方案及边界实证”是否满足导师对独立贡献的要求。若要求明确的新机制，当前第一点仍有贡献强度缺口，不能靠换叙述关闭。
